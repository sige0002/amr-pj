# 上置きモーター／ベルト案の独立レビュー

2026-09-20。第一案 `cad/amr01/build_chassis.py`、同README、`docs/amr-01/design_parameters.json`を読み、上置き案を担当して比較した。製作承認・購入選定ではない。

**推奨は低位置の同軸駆動＋金属の箱形車輪支持を第二案の主案とし、上置きベルト駆動を比較配置CADに残すこと。** 上置きは整備空間を作れるが、FIT0185では支持付き中間軸を追加する必要があり、同じ箱形支持の低同軸案Bに対して費用面で不利。Bが第一案Aより安いという意味ではない。支持構造の改善とモーター位置の変更は別々に評価する。

## 比較の共通条件と実例

AmazonのNFSL6-3030定尺400mm×4・300mm×2、フレーム460×300mm、床からフレーム下面75・上面105mmを維持する。台車は電池・電装込み10kg以内、荷物2kgと将来アーム2kgは別枠で総質量14kg。低価格・個人加工・整備を優先し、化粧外装を設けない。車輪100mm、FIT0185、左右独立駆動を比較の共通項とする。

ユーザーは「別に第一案のフレームの下がダメと言ってるわけではない」と明確化した。下置き自体を否定する要求はなく、上置きも比較対象に含めるという意味として扱う。Bは下置きを維持する。B・Cともタイヤと側面L金具の隙間を確保するため、車輪中心を左右170mm、輪距340mmへ変更した。軸受支持中心115／192mmは維持する。

- タミヤTA07 PROは、モーターマウント、独立したセンターシャフト、軸受、スパー／プーリーを組み合わせている。模倣する要点は「伝達軸を別に支持する」構成で、RCの小さな軸受やモーター配置を14kg台車へそのまま流用することではない。[メーカー組立説明書 p.6、p.8](https://www.tamiya.com/cms/english/rc/rcmanual/58636.pdf)
- AndyMark AM14Uは内外の側板、軸受、駆動出力軸、ベルトを組み合わせ、外側板の軸受を出力軸へ組み付ける。箱形支持とベルト伝動を分けて設計する実例として使える。6輪・大出力のFRC機であり、寸法・重量・価格は今回の採用候補ではない。[メーカー組立説明書 p.10–12](https://files.andymark.com/AM14U_AssemblyInstructions.pdf)

## 具体的な上置き配置

座標は第一案と同じ。左右とも車輪軸を `(x,z)=(90,50)mm` とし、上軸は左 `(135,127.94)`、右 `(45,127.94)` とする。前後差45mm、高低差77.94mmなので、軸間距離 `C=√(45²+77.94²)=90mm`。左右モーターを前後90mmずらすため、後端が中心線を少し越えても相互干渉を避ける余地を作れる。

S3M・30歯同士、ベルト幅10mmを比較用の仮寸法とする。ピッチ径は `30×3/π=28.65mm`、ピッチ周長は `L=2C+30×3=270mm`。三ツ星にはS3M270・90歯のサイズがある。ただし幅、材質、軸穴、ボス幅、取付張力、伝動容量、個人購入価格を確定したBOMではない。S3Mと他の3mmピッチ歯形は混用しない。[三ツ星サイズ表](https://product.mitsuboshi.com/industry/timing-belt/in_ti_08/size_s3m/)、[MISUMI S3Mプーリー](https://jp.misumi-ec.com/vona2/detail/110300405940/)

**ベルトを3030の間へ通すことが配置の要点。** 内側長手材の外端は `|y|=80`、外側長手材の内端は120mmなので、幅40mmの隙間がある。最初はベルト面 `|y|=106` を検討したが、第二案の箱内壁105～109mmとは干渉する。この箱を使う比較CADではベルト面を94mmへ寄せる。幅10mmの走路は89～99mm。プーリー全幅を仮に18mmとすれば85～103mmだが、実製品のボス・フランジ全幅が収まるか再確認が必要。

上側はモーター前面 `|y|=32`、カップリング42～67mm、8mm中間軸を軸受中心76／114mmで支持し、その間の94mmへプーリーを置く配置を出発点にする。KP08相当の軸心高15mmなら足座面はz112.94mm。支持台にはベルトの通し窓を設ける。全面の板を張ると、斜めのベルトが板を貫通してしまう。モーター外周の上端は約146.5mmで、局所ガードを含め約150mmを仮配置枠とし、160～180mmのデッキ高さへ納める余地がある。

箱外壁が約202mmの場合、下側の軸はプーリーから外軸受まで届く125mm以上が必要。第一案の100mm軸を無加工で流用できる配置ではない。下プーリーの内側張出し荷重、カラー、ハブ止めねじの工具アクセスも要検証。

張力調整は、モーターと上側2軸受を載せた台を一体で動かす。前後x方向±10mmの調整例ではC約85.4～95.4mmとなる。これは装着・調整範囲であり、最大位置までベルトを伸ばす指示ではない。モーター単独の移動はカップリングの芯を外す。

## 速度と軸荷重

FIT0185は無負荷83rpm、205g、拘束45kgf·cm≒4.41N·m。確認したメーカー仕様には連続トルクと許容ラジアル荷重がない。[DFRobot仕様](https://wiki.dfrobot.com/fit0185/)

| 駆動／従動の歯数 | 車輪の無負荷回転数 | 100mm輪の無負荷直進速度 |
|---|---:|---:|
| 30／30 | 83.0rpm | 0.435m/s |
| 30／45 | 55.3rpm | 0.290m/s |
| 30／60 | 41.5rpm | 0.217m/s |

30／45、30／60は比率比較であり、上の270mmベルト・C90mmとは別設計。最終比較の輪距340mmでは初期の0.15m/s＋0.3rad/sに外輪38.388rpm、将来の0.3m/s＋0.6rad/sには76.776rpmが必要。1.5:1減速は無負荷でも直進0.3m/sへ届かず、2:1は初期同時指令にも余裕が小さい。FIT0185を維持するなら**1:1**とし、負荷時速度・温度・電流を実測する。1:1でも将来の同時最大指令を保証しない。

現行仮定の5度、転がり抵抗0.03、加速度0.2m/s²、余裕1.5を14kgへ適用すると、1輪の必要トルクは次式で約0.708N·m。

`T=1.5×[14×0.2+14×9.81×(sin5°+0.03cos5°)]×0.05÷2`

30歯の有効張力差は `ΔF=T/r=0.708/0.01432=49.4N`。軸への力は張り側と緩み側の合計なので、この差より大きい。例えば各スパンの静止時張力を40Nと仮定すれば静止時軸荷重は約80Nとなるが、これは推奨張力値ではない。拘束トルクを同じ半径へ換算した張力差は約308Nにもなる。メーカー資料でも取付張力による軸荷重を考慮し、軸間距離の調整を求めている。[MISUMIの張力・軸荷重説明](https://jp.misumi-ec.com/tech-info/categories/technical_data/td03/a0109.html)

したがって、FIT0185出力へ直接ベルトを張る案は許容荷重が確認されるまで推奨しない。**カップリング→別軸→2軸受の間のプーリー**とし、ベルト荷重を金属支持台へ流す。PLAはベルト・軸端の着脱ガード、配線保持、穴位置確認用治具に使い、予張力を保持する主要支持には使わない。

## 費用・重心・整備と採否

同じ箱形車輪支持の低同軸案に比べ、上置きはプーリー4、ベルト2、中間軸2、軸受4、調整台2、長い車輪軸、ガードが増える。**追加8,000～15,000円を未見積の予算枠**とする。安価な部品を仮定した比較幅で、MISUMI製伝動部品の正式価格や送料を確認した金額ではない。既存カップリングは上へ移すので削減されない。両案共通の箱形支持変更・公式接合金具への変更費も、この差額に混ぜない。

主担当のB集計は自加工49,763円・外注加工込み64,763円で、第一案Aの34,159円・40,159円に対してそれぞれ15,604円・24,604円増える。箱形支持等を追加した結果であり、第一案より安くなった案ではない。本レビューの「低同軸の方が安い」は、共通の箱形支持を持つBと上置きCの相対比較に限る。

モーター2個0.410kgを77.94mm上げるだけなら、10kg台車の重心上昇は `0.410×77.94/10=3.20mm`。総14kgなら2.28mm。上軸、追加軸受、台、ガードの影響は含まれないため、完成重心の予測値ではない。重心だけで上置きを却下するほどの差ではなく、今回の主要な不利は部品費・加工・張力管理である。

| 評価点 | 低同軸＋箱形支持 | 上置き＋支持付きベルト |
|---|---|---|
| 車輪荷重 | 内外軸受→箱壁→フレームへ短く伝える | 同じ支持改善が必要。上置き自体では改善しない |
| モーター交換 | 車体下側への工具アクセスが必要 | 上からアクセスしやすい。台ごと着脱できる |
| 調整・消耗品 | 軸芯、継手、止めねじを点検 | 左記にプーリー整列、張力、ベルト交換が加わる |
| 加工 | 箱板・穴・側面締結 | 左記＋支持台の窓、長穴、追加軸の長さ調整 |
| フレーム・外形 | 高さ75～105mm維持 | 同じ高さを維持可能。上部の積載・電装空間を使う |

担当間の議論で、車輪支持担当から「短い荷重経路が本質」、要求担当から「重心差と追加費を分離」と指摘を受け、上置き側からは、輪中心y151のままでは元の3030にタイヤが干渉する点と、ベルト面y106が新しい箱内壁に干渉する点を差し戻した。箱形支持の効果を上置きの効果として扱わないことで一致した。

上置きを主案へ変更する条件は、低位置のモーターが電池・配線や必要地上高を妨げると配置で確認できること、整備上の利益が追加費用を上回ること、独立支持・ベルト容量・取付張力・交換手順が確定すること。現時点ではその根拠が揃わず、費用優先の主案は低同軸とする。
