# 変更履歴

## v0.2.1 — 2026-09-20

内部構造図を設計書へ組み込み、「外面をよくする必要はない。化粧外装は不要、内部構造を優先する」を明文化した。必要な機能保護カバー・非常停止・電池保護は残す。外観用コンセプトボードは採用しない。

図の概念表現と数値設計を区別し、上下二段の全面フレーム、大きな天板、減速機への車輪直結、前後左右の描画を製作条件として確定しない旨を追記。機器配置・配線・保守空間の確認項目を追加。

寸法・重量・駆動・安定性の計算条件と20件の既存回帰テストは維持。設計方針と図の同梱を確認する4件を追加した。画像は閲覧用WebPへ縮小・圧縮。画像内容の機械的妥当性や製作成立をテストしたものではない。

GitHubの`docs/amr-01/`で現行文書を管理し、`archives/amr_v0_2_1.zip`を配布用に生成する。既存の`cad/`は本更新の対象外。

## v0.2 — 2026-09-20

ユーザーの「前案は重すぎて家に入らない。可搬2kgでよい」という条件に合わせて概念設計を更新。

|---|---|---|
| 運搬物 | 5kg | 2kg。アーム自重とは別 |
| 外形 | 520×420mm | 350×280mm、車輪・ガード込み |
| 台車自重 | 約18kg | 目標5kg、上限6kg |
| アーム系 | アーム10kg＋グリッパー1kg | アーム・グリッパー・専用取付/電装/電源等を合計2kg以内に仮設定 |

| 床からの把持物 | 2kgを目標 | 未確定。荷台2kgの運搬と分離 |
| 主フレーム | 30角、上下二段 | 20角、低い主フレームと補強板 |
| 車輪径 | 160mm | 100mmを仮設定 |

| 予算 | 15万円の仮配分 | 未確定。見積金額として引き継がない |

### 追加した事項

重量目標5kgを区分別に配分。外形と旋回包絡を分離し、車体のみで約599mmの旋回直径を計算。台車5kg・6kgで静的安定性を再計算し、仮の前方姿勢では2kg把持が転倒側になる点を明記。

入力値を`design_parameters.json`へ分離。把持上限は`null`とし、感度計算の物体質量を把持許可値と誤認させない。全姿勢・動的安定性・実機安全性は未検証。

旧版にあった「30角が必須」「大型アームに備える」「床2kgを拾う」といった前提を現行必須条件として引き継がない。過去の把持能力に関する記述よりも、今回の小型軽量化と未確定事項の分離を優先した。

旧版ファイルは変更せず履歴として残し、現行版を`amr_v0_2`として別管理する。
