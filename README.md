# amr-pj — 家庭向け小型AMR / 将来MoMa

家庭内用の小型AMRから、将来の移動マニピュレータ（MoMa）化を目指す設計プロジェクト。

**外面をよくする必要はありません。見栄えのための外装・化粧カバー・装飾は不要です。内部構造、荷重支持、機器配置、配線、放熱、保守性を優先します。** 巻き込み防止・電装接触保護・端部保護など、機能上必要なガードは残します。

## 設計資料

- [現行設計書 v0.4.0](docs/amr-01/DESIGN.ja.md)：Amazonで購入する3030フレーム、内部構造、配置、重量予算、駆動・転倒・停止の検討。
- [設計書・計算ファイル一式 ZIP（画像なし）](archives/amr_v0_4_0.zip)：展開して読める配布用パッケージ。
- [変更履歴](docs/amr-01/CHANGELOG.ja.md) / [計算の実行方法](docs/amr-01/README.ja.md)。
- [第一案CAD・実画面・部品表・費用](cad/amr01/README.ja.md)：3030フレーム、モーター、車輪、軸受、キャスター、取付板を配置。
- [FreeCAD環境と従来サンプル](cad/)

| 項目 | 現行の設計目標 |
|---|---|
| 外形 | 500×400mm（配置目標）、車輪・必要な保護ガード込み |
| 主フレーム | 30角、組立案460×300mm。材料代3,419円（税込、金具・送料等別） |
| 高さ | 160〜180mm、アーム・センサーポールを除く |
| 台車自重 | 配分目標6kg、上限6kg。電池・搭載計算機・センサー込み |
| 運搬物 | 2kg。アーム自重とは別 |
| 将来のアーム系 | 合計2kg以内の仮予算。把持重量は未確定 |
| 機構 | AmazonのミスミNFSL6-3030、300mm・400mm材、直径100mmの左右駆動輪、後方中央キャスター |
| 速度 | 初期0.15m/s、検証後上限0.3m/s |

**概念設計です。製作CAD・強度・停止・実機運用を保証する資料ではありません。** 生成画像は不正確なため、設計書・配布ZIPに含めず、設計根拠に使用しません。v0.4.0では購入部品を選定し、第一案CADを作成。実CAD画面はユーザーの依頼により保存しています。

## 第一案の費用と現状

機械骨格の購入品小計 **24,409円**。板材・追加ねじ・送料の予算込みで **34,159円**、加工を外注する予算込みで **40,159円**。電池・ドライバ・計算機・センサー・ガード・アームは別です。

骨格は概算 **4.73kg**。従来の電装等予算を加えると **6.78kg**で、6kg目標は未達。FIT0185の連続トルクと購入品の未公開寸法も確認待ちです。詳しくは[第一案の設計説明](cad/amr01/README.ja.md)を参照してください。

## 再計算とZIPの生成

Python 3.10以降、追加パッケージ不要。

```bash
cd docs/amr-01
python3 check_design.py
python3 -m unittest -v test_check_design.py
cd ../..
python3 tools/build_design_archive.py
```

テスト合格は実機安全性の認定ではありません。`archives/`のZIPは上記スクリプトで生成します。
