# A5：可搬15kg・安全率2に向けた荷重と強度の比較

2026-09-21。**現段階は、要求・荷重・製造費を比較する設計候補であり、安全率2の認定やFEA完了を示すものではない。** 金具の総断面には計算上の余裕を見込める一方、固定端の接触、小ねじとその母材、3030溝・溝ナット、締付予圧、局所応力と変位が未評価である。総25kgでは旧5°条件の駆動余裕も不足する。

入力は [requirements.json](requirements.json)、計算は [calculate_mount_loads.py](calculate_mount_loads.py)、全数値は [load_calculations.json](load_calculations.json)。旧A4以前の14kg計算は履歴として比較に残し、今回の現行荷重要件とはしない。

幅75・フランジt6のD5を追加比較した。幅90/t5のD1/D2は基準値として保持し、最初の幅75/t5案は不採用の感度履歴とした。t6化は単純梁への置換では幅削減分を補うが、狭くしたM6間隔、受け周囲の肉幅、根元形状、実接触まで同じ性能になるとはいえない。最終の[実見積](MACHINING_QUOTE.ja.md)は2個80.08 USDでA4の74.50 USDより高く、D5は比較CAD・仮合わせモックに限定した。

## 暫定要求と計算範囲

「可搬15kg」が荷物重量を指すかは回答待ち。本書は**車体上限10kg＋荷物15kg＝総25kg**を仮定する。将来アーム2kgも別に同時搭載するなら27kgとなり、25kgの主ケースには含まない。荷物15kgをアームで持ち上げてよいという意味でもない。

| 項目 | 現在の入力と扱い |
|---|---|
| 静的安全率 | 降伏・締結強度の目標2。衝撃係数・剛性とは別 |
| 剛性 | 軸部変位0.1mmを候補とする。基準点・方向・受入値は未確定 |
| 主荷重比較 | 片輪に全重量が掛かる245.166N、線形強度比較の2倍荷重490.333N |
| 横力 | 未決定。左輪外向きFy/P=0、0.1、0.5の感度を併記。0を採用条件としない |
| 駆動トルク比較 | 公表定格0.96N·mと拘束2N·m。2を許容運転ピークにしない |
| モーター・骨格 | M0601C_111、3030の460×300、フレームz69〜99、車軸高50.35、長いスペーサーなし |
| D1 / D2 | 共通：幅90、フランジt5、ウェブ幅60/厚17、受け深9/背肉8、根元R2。受け隅RはD1=2、D2=2.5 |
| D5の現比較 | 幅75、フランジt6、ウェブ幅45/厚17、M6ピッチ60。受けR2/深9/背肉8は維持、根元は長辺2本のR2 |
| D5の旧感度 | 同じ幅75/ウェブ45/M6ピッチ60でt5。t6へ変更前の比較履歴として保持 |

重力加速度は9.80665m/s²。旧計算の9.81からの差は約0.03%。ここでは全数値を同じgで再計算する。

片輪245.166Nは、搭載位置が未定の段階で金具を比較するための上限ケースである。平床で三輪反力が非負なら一輪反力は全重量以下だが、一輪に全重量を寄せる状態は支持三角形の頂点に近い限界であり、通常の安定走行姿勢ではない。左右輪とキャスターへ同時に全重量を掛ける計算にはしない。段差・再接地による衝撃、疲労、荷台の局所支持は別条件として残る。

## 重心による各輪反力

左右輪の接地点は(90,±174.5)mm。キャスターは中心(−150,0)mmから16mm偏心し、720方位をサンプルする。合成重心投影(xg,yg)、全重量W、キャスター接地点(xc,yc)に対して、

```
Rc = W (90-xg)/(90-xc)
RL-RR = (W yg - Rc yc)/174.5
RL+RR = W-Rc
```

を用いる。総荷重を三等分しない。合成CGはすべて未実測の仮定である。

| ケース | 合成CG (x,y,z) mm | 最大駆動輪反力 | 最大キャスター反力 | 最小支持辺余裕 |
|---|---|---:|---:|---:|
| 履歴：14kg、アーム収納＋荷物2kg | (3.857,0,116) | 46.70N | 52.80N | 81.06mm |
| 25kg、荷物CG(−10,0,190) | (−6,0,148) | 78.91N | 105.07N | 74.84mm |
| 25kg、荷物CG(0,0,190) | (0,0,148) | 81.64N | 98.50N | 78.62mm |
| 偏積み感度：荷物CG(100,100,190) | (60,60,148) | 151.08N | 32.83N | 30.00mm |

最終行を許可された積載範囲と扱わない。高さは平床静止の鉛直反力に直接は現れないが、加減速・傾斜・転倒には影響する。荷物のCG範囲、支持台、固定方法を決める必要があり、電池・電装用PLAトレイを15kg荷台へ読み替えない。

## 現行メーカー荷重値との比較

[メーカー現行M0601C-111仕様](https://shop.directdrive.com/pages/m0601c-111-specs) は、**許容ラジアル120N、アキシャル60N**を掲載している。ただし荷重点、ラジアル/アキシャル同時負荷、寿命・衝撃条件、内包する安全率は記載されていない。旧資料の製品ロットへの適用も未確認。現行電圧範囲7.5〜28Vと旧説明書の最大24Vなどの版差があるため、型番名だけで適用済みとしない。

公開許容値を無断で2除算して「安全率2未達」とは判定しない。120N/60Nは降伏荷重ではなく、今回の金具の強度倍率とは別の指標である。

それでも、購入品と荷重点へ適用できるなら、上記偏積み例は鉛直反力だけで151.08Nとなり公開120Nを上回る。片輪全重量245.17Nの比較も同様であり、金具を強くしてもモーター側の条件は解決しない。中央寄り例の78.91/81.64Nが120N未満でも、運転成立の証明にはならない。

本コードは参考としてサービス荷重の `sqrt(Fx²+Fz²)` をラジアル力、`|Fy|` をアキシャル力の比較値とする。支持位置に伴う曲げや複合荷重の許容判定ではない。Fy=0.5Pの感度では122.58Nとなり公開60Nを超えるが、0.5P自体が実測または承認した横力ではない。**比較は倍率前のサービスベクトルに対して行い、490Nの強度用等価荷重を公開許容値へ直接当てはめない。**

[420G-R50](https://www.hammer-caster.co.jp/products/detail/3119) の許容荷重は30daN=300N/個。これも降伏荷重ではなく、300Nと使用荷重の比から静的降伏安全率を認定しない。

## D1/D2基準断面と横力感度

左輪接地点(90,174.5,0)に(Fx,Fy,P)を与え、レール下面の接合中心(90,135,69)へ移す。

```
Fx = 1000T/50.35
Mx = 39.5P + 69Fy
My = -69Fx
Mz = -39.5Fx                    [N·mm]
```

駆動トルクを別に再加算しない。P=245.166N、Fy=0でMx=9.684N·m。T=2N·mではFx=39.72N、|My|=2.741、|Mz|=1.569N·m。

穴のない矩形断面に `σ=6Mx/(bt²)` を用いた結果は次のとおり。幅60は有効幅を保証する値ではなく、荷重が狭い範囲を流れる影響を見る仮定である。

| 横力感度 | Mx | 使用荷重時・幅90/t5 | 使用荷重時・幅60/t5 | 全外力2倍時・幅60/t5 |
|---|---:|---:|---:|---:|
| Fy=0 | 9.684N·m | 25.82MPa | 38.74MPa | 77.47MPa |
| Fy=0.1P | 11.376N·m | 30.34MPa | 45.50MPa | 91.01MPa |
| Fy=0.5P | 18.142N·m | 48.38MPa | 72.57MPa | 145.14MPa |

調達要求の仮定をA6061-T6、最低0.2%耐力240MPaとすれば、安全率2に対応する使用応力の目安は120MPaになる。[JLCCNCの6061資料](https://jlccnc.com/help/article/aluminum-6061-cnc-machining) に240MPa以上の記載はあるが、径70mm以上の試験片などの注記があり、今回の切削素材の証明書とはしない。JSONでも「調達要求240」と「保証済み耐力null」を分けている。

上表の粗応力が120MPa未満という比較は可能だが、全相当応力、切欠き・孔・根元R、面圧、締結、実接触を含まない。したがって表から部品の安全率2達成は宣言できない。D1とD2はこの粗断面計算が共通であり、R2→R2.5による局所応力の低下量や適合の優劣を計算したものではない。

## M6とM2.5の荷重経路

金属一体金具は、受けポケット・固定端面・M2.5から、ウェブ、フランジ接触、M6と溝ナットへ荷重を伝える。隙間ばめのポケットを設けたことだけでM2.5を無荷重にしない。

M6はD1/D2基準でx方向75mmピッチ、y方向は一列。Mxは外側面の接触圧縮とねじ引張の対で受ける。接触合力のy方向腕をaと仮定すると `C=Mx/a`、二本分の追加引張成分は `C−P` で、Myによる一本当たりの差は `±My/75`。D5は分母を60とする。接触腕a=9.5/15mmは仮定であり、実際の接触分布から得た値ではない。

基準D1/D2のP=245.166N、Fy=0について以下の値となる。

| 比較量 | T=0.96N·m | T=2N·m |
|---|---:|---:|
| M6一本の最大追加引張成分：a9.5 | 404.65N | 423.65N |
| 同：a15 | 217.76N | 236.76N |
| 摩擦ゼロモデルのM6最大面内せん断 | 13.85N | 28.85N |
| 受け・面摩擦の分担ゼロモデルのM2.5最大せん断 | 121.32N | 167.71N |
| 三点同剛性ばねモデルのM2.5引張方向最大値 | 445.35N | 502.62N |

M2.5はPCD15.2の三点について直接荷重とモーメント成分を配分し、圧縮側も含むモデルである。上表は実ボルト軸力や許容値ではない。非ゼロFyを含む基準12荷重ケース、履歴D5 t5の12ケース、現比較D5 t6の12ケースと各ボルトの符号付き成分をJSONへ保存した。

安全率2を線形部材への倍率として比較する場合、P、Fx、Fyと全モーメントを一緒に2倍する。Pだけ2倍、Tをそのままにした結果とは異なる。等価T=4N·mが現れても、モーターが4N·m出せることを意味しない。予圧を含む締結評価は、この倍率表だけで完了しない。

優先する残課題は次のとおり。

- **M2.5母材・締付け・局所座面：** 固定側深さは旧[メーカー説明書p8](https://d2air1d4eqhwg2.cloudfront.net/media/files/a48110eb-432c-4083-a159-9e0f35913b23.pdf#page=8)で5mm。現12mmねじ/背肉8mmは公称4mm食込み、底付き余裕1mm。ねじ等級、母材、実ねじ長、締付条件は未確定。
- **スリット近傍：** φ2.8孔と幅7溝の横肉1.682mm、φ4.5頭の座面端余裕0.832mm、公称環状座面9.75mm²。粗い幅60ウェブ断面でこの部分を保証しない。
- **受け長さ：** 受け両端だけで全曲げを負担する極端な比較では、深さ9mm/P245Nで内端−749N、外端994N。深さ3mmなら−2,738/2,983N。実接触力ではないが、浅くして加工費を下げると接触と小ねじへ負担を移し得る。
- **3030側：** M6頭/孔の環状座面44.3mm²、座金なし。予圧、座面沈み、こじり、溝ナットとレール溝縁の引抜き・滑り・局所変形を別に確認する。完全固定境界はこれらを評価しない。
- **横力・疲労：** 定常旋回の全体慣性力だけで、左右で打ち消し合う横力、有限接地面のねじり、キャスター過渡抵抗は決まらない。床・制動・旋回・段差の使用条件が必要。

## 軸部変位と受け隙間

0.1mmは未承認の候補。使用荷重245.166Nでその変位を目標とするなら総合剛性2,451.66N/mmが必要になる。まず軸中心から局所レールまでか車体基準までか、鉛直・横・角度をどう評価するかを決める。

現スカラー寸法の公差を使うと、受け平面とモーター平面の片側隙間は**0.05〜0.45mm、公称0.25mm**。主円弧は**0.125〜0.325mm、公称0.20mm**。端面が締結で保持する間にそのまま同量動くわけではないが、ポケット完全接着と小ねじ無荷重を同時に仮定できない。D1/D2/D5の隅Rを含む全輪郭の適合は、これらの平面・主円弧の計算とは別に照合する。

内蔵軸受、受け接触、端面締付、ウェブとフランジ、3030の溝・ナット、レール曲げとねじりまでの変形を考える。参考として400mmの3030一本を単純支持し、端から290/110mmの位置に245.166Nを加えると、I=26800mm⁴、E=69000MPaで荷重点たわみ0.1124mm、曲げ応力10.94MPaとなる。[MISUMI断面資料](https://jp.misumi-ec.com/special/alumiframe/tech/capacity_guideline/)

この支持条件は実車を同定したものではないので、0.1mm不合格の判定には使わない。金具単体の完全固定解析だけで車体全体の変位を代表できないことを示す比較である。FEAを行う場合は、実R、面接触、隙間と予圧、荷重分布を設定し、角点のメッシュ依存応力をそのまま安全率へ変換しない。

## 旧5°条件と平地候補

左右等分の駆動力、r=0.05035m、a=0.2m/s²、Crr=0.03に対し、

`T=m(a+g sinθ+Crr g cosθ)r/2`

を使う。駆動選定の余裕係数1.5は、金具の安全率2と別である。

| ケース | 係数前/輪 | 駆動係数1.5後/輪 | 公表定格0.96との比（係数後） |
|---|---:|---:|---:|
| 履歴14kg/5° | 0.4750N·m | 0.7125N·m | 1.347 |
| 暫定25kg/5° | 0.8483N·m | 1.2724N·m | 0.754 |
| 暫定25kg/平地 | 0.3110N·m | 0.4666N·m | 2.058 |
| 別解釈の参考：総重量15kg/5° | 0.5090N·m | 0.7634N·m | 1.257 |

25kg/5°は従来の余裕条件を満たさない。平地等速のみなら係数後0.2777N·m/輪。同じa/Crr/係数で計算上の定格へ達する勾配は約3.058°、5°での総重量は約18.862kgだが、運用許可値ではない。低速化だけでは登坂の重力トルクは減らない。

メーカーの0.96N·mは18V/115rpmの公表定格であり、初期約38rpm、停止保持、実電圧での連続温度を保証する値ではない。拘束2N·mで不足分を補わず、旋回抵抗、低速熱、電圧降下、制動と摩擦条件を確認する。[現行メーカー仕様](https://shop.directdrive.com/pages/m0601c-111-specs)

## 再現と検証

リポジトリのルートで実行する。

```sh
python3 cad/amr06/calculate_mount_loads.py
python3 cad/amr06/calculate_mount_loads.py --check-only
```

通常実行は同じディレクトリのJSONを更新する。`--check-only`はファイルを書かない。外部ライブラリは不要。D1/D2/D5の幾何変更や荷重変更は入力と照合してから再実行する。

確認したのは2,880姿勢の力・モーメント釣合い、重心を各支点に置いた極限、左右鏡映で反力が入れ替わること、3形状群/36荷重ケースのM2.5とM6接触モデルの釣合い、全外力の倍率整合である。D5追加前後でD1/D2の既存荷重・CG・駆動・隙間/梁計算値が完全一致することも確認した。最大残差は力1.82×10⁻¹²N、モーメント1.28×10⁻¹¹N·mm以下。これらは計算の物理整合の検算であり、公称CADの干渉確認、材料証明、実機試験、FEAを代替しない。
