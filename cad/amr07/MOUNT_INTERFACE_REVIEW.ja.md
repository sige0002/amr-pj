# A6 — モーター受け・小ねじ座面・3030締結の独立レビュー

2026-09-21。対象は `M0601C_mount_A6_R1` と [数値仕様](mount_interface.json)。DR01・DR02・DR07に対し、A4の幅90／フランジt5／M6ピッチ75を維持して、機能公差、組立着座、座金、実ナット寸法鎖を修正した。**幾何と調達仕様を具体化した段階であり、安全率2、締付け力、実機許容荷重を証明したものではない。** A4/D5の旧見積・旧ねじ重なり計算はこの形状へ自動適用しない。

要求は平坦な屋内床で通常荷物10 kg、構造検証は荷物15 kg＋車体最大10 kg。追加機械ブレーキは不採用とし、5°・荷物8 kgは参考計算に留める。モーターを含む運転条件は [要求仕様](requirements.json) と [荷重計算](load_calculations.json) に従う。25 kg全重量を片金具へ置く比較荷重245.16625 N、その2倍490.3325 Nは、実際の一輪常用荷重やメーカー許容荷重ではない。

## 1. 受け輪郭と3穴を別の基本位置にする

製作部品は90×30×34、web幅60／厚17、受け深9±0.10、背肉8±0.05 mm。固定端面の車体座標はy138を維持する。元既製ブラケットの解析輪郭を一様に外向き0.12 mmオフセットし、円弧だけの変更による接線の再設計を避ける。元既製品は受け深3・背肉7であり、本金具の深9・背8は独立した設計である。[元輪郭の一次データと読取り](../amr05/BRACKET_SOURCE_REVIEW.ja.md)、[既製ブラケット販売元](https://www.switch-science.com/products/9204)

| 機能部 | A6指定 | 指定の目的 |
|---|---|---|
| 受け輪郭 | 主円弧R9.67、平面軸距離8.22、小円弧R1.62、すべてBASIC | 元輪郭の一様オフセットを保持 |
| 受け全壁 | 面の輪郭度0.10、対称配置、A\|B\|C | 円弧・平面・小Rの形状と位置をまとめて制限 |
| 受け中心 | 車体(x,z)=(90,50.18) | 上向き着座分0.17を名目高さへ織り込む |
| 孔群中心 | 車体(x,z)=(90,50.35)、PCD15.2 BASIC | ねじ・モーターの名目軸を維持 |
| 3通し穴 | φ3.2 +0.10/0、位置度φ0.10、A\|B\|C | 着座後の偏心をねじ軸が吸収 |
| A | 3030接触面、平面度0.05 | 取付面基準 |
| B | モーター端面座、平面度0.05／Aへの直角度0.05 | 端面を押し付ける基準 |
| C | 幅90の対向外面から導く中央面 | 左右位置基準 |

図面ローカル原点は車体(45,120,35)。受け中心はX45/Z15.18、孔群中心はX45/Z15.35。3孔のX/Z基本座標は (45,22.95)、(38.4182069312383,11.55)、(51.5817930687617,11.55)。穴と受けを同心へ戻さない。輪郭度に位置誤差を含めるため、さらに独立の受け軸±0.05を重ねて公差を二重加算しない。その他の非機能寸法に全体一律±0.05を要求する必要はない。

公表固定端はφ19 +0.05/−0.15、平面軸距離8±0.15、PCD15.20±0.08、固定側3×M2.5・深さ5 mm。PCD公差だけでは孔の角度・軸心・ボスとの位置関係は確定しない。**モーター孔群位置誤差を半径0.05以下とする値は、本設計の受入条件であり、公表保証値ではない。** 購入ロットの全輪郭・孔群・端面を測定する。[メーカー資料p8](https://d2air1d4eqhwg2.cloudfront.net/media/files/a48110eb-432c-4083-a159-9e0f35913b23.pdf)、[公開モーターSTEP](https://github.com/takasumasakazu/DirectDriveTech_test/blob/main/STEPdata/M0601C_111.STEP)

円弧の中心位置が一致した状態の半径すき間は0.095〜0.295 mm。斜面の最小法線すき間は8.17−8.15=0.020 mmで、その法線の鉛直成分0.5を使うと上向き移動0.040 mmで斜面が先に当たり得る。したがって着座は「上側円弧に必ず接触」ではなく、**タイヤ反力側の受け輪郭へ接触**させる。単純な円弧・平面の独立寸法端による着座量の包絡は0.040〜0.295 mm、装着軸高はz50.220〜50.475、名目50.35から−0.130/+0.125 mmとなる。小R、角度ずれ、端面傾き、横方向の座りを含む全輪郭の適合保証ではなく、実測と3本同時挿入で確認する。

条件付きのねじ挿入判定は次式で行う。

```text
max|着座量−0.17| + 金具孔位置誤差 + モーター孔位置誤差 + 組立予備
    ≤ (最小穴径−最大ねじ軸径)/2
0.130 + 0.050 + 0.050 + 0.050 = 0.280 ≤ (3.2−2.5)/2 = 0.350 mm
```

組立予備を除く最大中心差は0.230、片側残余は0.120 mm、予備を含めた残りは0.070 mm。これはねじを穴へ無理なく挿入する比較であり、全方向の回り止め、ねじへ荷重が一切伝わらないこと、摩擦締結の成立を示さない。タイヤ・モーターの実装高さと荷重時のタイヤたわみを測り、キャスター接地を合わせる。

## 2. M2.5直下は鋼製小径座金で受ける

JISのM2.5六角穴付きボルトでは、頭部外径最小4.32に対し有効座面径は最小4.18、首下丸み包絡径daは最大3.1 mm。偏心したφ3.2穴へ頭を直接載せ、穴口C0.1以下だけを指定する案では、首下丸みの当たりと座面不足を十分に扱えない。このため、背面3箇所に**φ6.2 +0.10/0×深0.50±0.05の浅座ぐり**を設け、OD5／ID2.7／t0.5の小径平座金を入れる。座ぐりの軸にも位置度φ0.10、A\|B\|Cを適用し、通し穴と同じ基本位置に置く。底面は端面座Bに平行な平らな座面とする。[NBKによるJIS B1176:2015抜粋](https://www.nbk1560.com/images/ja-JP/product/technical_data/rokkaku_bolt_NBK/rokkaku_bolt_NBK_1.pdf)

実在する少量調達候補は、ねじ **WILCO FC-2512**（日産ネジ、SCM435、黒色酸化被膜、JIS B1176、12.9、M2.5×12）、座金 **FW-2505-05EB**（鉄、三価クロメート黒、2.7×5×0.5）。各6個を使用する。確認時掲載価格は10個以上でねじ25円/個、座金29円/個（いずれも税別）、送料別。座金10個の税込材料費は319円。注文は行っていない。[ねじ販売元](https://wilco.jp/products/F/FC.html)、[座金販売元](https://wilco.jp/products/F/FW-EB.html)

座金の受入寸法はJIS B1256小形・部品等級A相当としてID2.70〜2.84、OD4.7〜5.0、厚0.45〜0.55 mmを用いる。**販売ページは当該規格への適合・硬さ・内口形状を明記していない**ため、候補品がこの範囲を満たすことは別に確認する。規格番号を付けただけで硬化座金やDIN433適合品と扱わない。[NBKによる平座金規格抜粋](https://www.nbk1560.com/images/ja-JP/product/technical_data/hira_zagane_NBK/hira_zagane_NBK_1.pdf)

座金の穴遊びは最大(2.84−2.36)/2=0.240 mm。孔群との中心差0.230に加えると、座金外周の最大中心ずれは0.470 mmとなる。最小φ6.2座ぐり内には半径0.130 mmの余裕が残る。下2箇所の配線背側開口を幅6.5±0.10に絞ると、開口位置ずれを除く座金外周の最小残りは

```text
6.5817930687617 − 6.6/2 − 5.0/2 − 0.470
    = 0.3117930687617 mm
```

である。座ぐりや開口の位置誤差、開放される縁、バリを実物で確認する。組立時は座金をねじへ追従させ、首元を含めて全周が平らに座ることを確認する。**内径2.7の座金とda最大3.1のねじの組合せは、呼び径が同じという理由だけで首下適合を保証できない。** 首元で浮いた状態を増締めで押し潰さない。

穴口C0.1以下による口径最大3.5、座金OD最小4.7を仮定した平面投影支持面積は7.7283179278309 mm²。ねじ頭側はdw最小4.18と座金ID最大2.84から7.3880834434471 mm²。この数値は全面着座を確認した後の面圧スクリーニング用であり、座金曲げ、端部丸み、硬さ、実予圧を含む許容力ではない。

| M2.5長さの寸法鎖 | 最小〜最大 mm |
|---|---:|
| JIS呼びL12の実長 | 11.65〜12.35 |
| 背肉 | 7.95〜8.05 |
| 座ぐり底までの残肉 | 7.40〜7.60 |
| 残肉＋座金 | 7.85〜8.15 |

公称は7.5＋0.5=8、12−8=4 mmで、A4の公称ねじ込みを維持する。先端不完全山を最大2P=0.90として差し引くと、完全山の重なりの粗下限は2.60 mmであり、さらに相手の導入山等を差し引く。図面の「深さ5」は、測定済みの硬い穴底や完全ねじ山長さそのものではない。DDSM115の深さ6を引き継がない。ねじの12.9等級からモーター側ねじ母材、引抜き強度、許可締付けトルクを推定しない。

## 3. M6は実ナットと溝から長さを計算する

従来CADの溝幅13・深さ8・リップ厚3、ナット12.8角×t4は実品を表していなかった。NFSL6-3030の公表断面は入口8、最大内幅16.5、リップ厚2、全溝深9 mm。溝の奥は斜面で狭まり、底には型式固有の細部がある。直方体の穴へ単に幅を拡大するだけでは実形適合を確認できない。[現行製品ページ](https://jp.misumi-ec.com/vona2/detail/110311092329/)、[現行断面図](https://jp.misumi-ec.com/linked/item/10311092329/img/drw_20_005.gif)、[溝・底部詳細](https://my.misumi-ec.com/pdf/fa/2014/p2_569.pdf)

HNTT6-6はS10C相当、鼻幅A7.8、本体最大幅B15、レール方向長さL14、本体厚E5.5、全厚T6.3、鼻突出T−E=0.8 mm。本体も溝奥側へ細くなる台形であり、15×14×5.5の単純直方体ではない。端部Rや裏側幅の全寸法は掲載図に独立指定されていないため、図から再構成する部分と確認済み寸法を分ける。[寸法付きメーカー図](https://sg.misumi-ec.com/pdf/fa/2013/p1871.pdf)、[現行HNTT6製品ページ](https://jp.misumi-ec.com/vona2/detail/110302610850/)

| 締付け状態の基準 | フレーム外面から内側への公称深さ | 下面溝の車体z | 上面溝の車体z |
|---|---:|---:|---:|
| ナット鼻先 | 2−0.8 = 1.2 | 70.2 | 97.8 |
| リップと接するナット肩 | 2.0 | 71.0 | 97.0 |
| ナット裏 | 2＋5.5 = 7.5 | 76.5 | 91.5 |
| 溝最深部 | 9.0 | 78.0 | 90.0 |

モーター金具はM6×12、座面z64、先端z76。公称の幾何重なりは76−70.2=5.8、溝最深部まで2.0 mm。ねじ長11.65〜12.35とフランジ4.9〜5.1だけを先に合算すると、侵入深さ6.55〜7.45、重なり5.35〜6.25、底余裕1.55〜2.45 mmとなる。ナット・鼻・リップ・溝の実公差、底の局所突起、面取り・不完全山をまだ含まないため、**5.8 mmを有効ねじ長保証と記載しない。** 男ねじ先端2P=2 mmを差し引いた粗下限3.35 mmから、さらに雌ねじ側等を差し引いて評価する。

実測値を用いる式は、外面からの侵入量 `p=L−被締結厚`、鼻先位置 `u=リップ厚−(ナット全厚−本体厚)`、幾何重なり `min(p,リップ厚＋本体厚)−u`、底余裕 `ねじ先端位置での実溝深−p`。有効重なりは幾何重なりから両側の不完全山などを除く。先入れナットはフレーム組立前に挿入し、レール端からの経路と隣接ブラケットの占有を確認する。

M6調達候補はWILCO **FC-0612**（SCM435、JIS B1176、12.9）またはMISUMI CB6-12。頭側だけC0.3±0.1を追加し、首元da最大6.8の逃げを設ける。最大穴口φ7.6と有効座面径dw最小9.38から、同心時の平面投影面積は23.7381882497898 mm²。旧計算の外径φ10／穴φ6.6から求めた44.3 mm²をそのまま使わない。実ボルト・ナットを孔へセンタリングし、頭部が平らに座ることを確認する。[調達候補](https://wilco.jp/products/F/FC.html)、[頭部・長さ規格](https://www.nbk1560.com/images/ja-JP/product/technical_data/rokkaku_bolt_NBK/rokkaku_bolt_NBK_1.pdf)

メーカーのナット参考締付けトルク11.7 N·mを、この薄いアルミ面と溝縁の接合へ無条件に指定しない。ボルト予圧、座面圧縮、接触面の浮き、すべり、溝リップ曲げ・引抜き、偏心モーメントを含む評価と締結試験が必要である。

## 4. 製作・組立・強度確認を分ける

1. 加工依頼では同名STEPと図面2頁を一組にし、輪郭度0.10、孔位置度φ0.10、背肉、座ぐり、座面、意図した中心差0.17を業者が認識したことを確認する。一般公差だけの自動見積へ戻さない。
2. 購入モーター、ねじ、座金、ナット、フレームの受入測定を行う。ボス全輪郭／孔群／端面、ねじ長さ・首元、座金の公差・平面性、実ねじ深さ、溝とナットの寸法を記録する。
3. モーターを車体+zの荷重側へ軽く着座させ、3本同時挿入・端面接触・座金全面支持・首元逃げを確認して締結する。配線は背側6.5±0.10へ通す。φ6の予約経路には幅だけなら最小片側0.20 mmしか余裕がなく、実配線の外径、保護材、曲げR、擦れを確認する。公開STEPの約φ4.8は線束の製品公差ではない。
4. 確認済み材料と実締結条件で、受けの局所面圧、ボスと端面の荷重分担、M2.5雌ねじ、座金曲げ、M6予圧・こじり、溝縁を評価する。現在の粗断面計算と干渉ゼロは、この検証の代わりにならない。
5. SF2の金具試験は別途定義した代表ボス治具で行う。モーターの現行公表値はラジアル120 N／アキシアル60 Nで、荷重点・版・組合せ則・内包安全率は未確認である。金具試験荷重245.16625/490.3325 Nを、そのまま実モーターへかける試験手順にしない。[現行メーカー仕様](https://shop.directdrive.com/pages/m0601c-111-specs)

DR01は機能公差と見積対象を具体化、DR07は実ナットに基づく寸法鎖へ修正した。DR02は荷重側着座と座金追加で改善したが、**接触・予圧・母材・完全ねじ山の強度成立は未完了**として残す。形状モック、計測、強度計算、静的試験、運転試験を同じ完了状態で扱わない。

検算はJSON読込み、M2.5寸法鎖の16端点組合せ、M6の4端点組合せ、上下溝へのナット座標変換、孔の片側すき間式を独立計算し、すべて一致した。見積図2頁を画像で確認し、CADの座ぐり・開口・面取り寸法と照合した。実物測定・実組立・荷重試験は未実施。
