# PLAの小型アダプタと配線ガイド

A6-D2のアルミ荷台下面へ取り付ける非構造部品。**荷台支持・モーター支持・重いアームの固定には使わない。** [実CAD画面](../cad-screen-grid-and-fixtures.png)。

| STL | 数量 | 造形時の外形 | 中実換算 |
|---|---:|---|---:|
| [アダプタL](PrintedAdapterL.stl) / [R](PrintedAdapterR.stl) | 各1 | 64×16×3.2mm | 各3.31g |
| [配線ガイドL](PrintedGuideL.stl) / [R](PrintedGuideR.stl) | 各1 | 64×23×12mm | 各4.71g |

STLは荷台との平面接触側をベッドへ向け、原点とz=0に配置済み。再読込みで水密メッシュを確認し、すべてP1Sの256×256mm以内に収まる。スライス・造形・現物嵌合は未実施。ナットポケットとガイドの天井はブリッジを含むため、スライサーで初層、薄肉、ブリッジと支持の要否を確認する。

アダプタは50mmピッチのM4格子へ固定し、20mmピッチのM3ナット2個を保持する。ナットは荷台に接する側から先に入れる。実機器の寸法と放熱は未選定。機器側M3ねじは荷台下面z114より先へ突出しない長さで決める。今回の汎用アダプタだけで、選定中の全電装が取り付くとはしていない。

ガイドはφ6mmの束に対する幅7mmの開放溝と、2.5mm結束バンド用3.2×1.2mm窓を持つ。片側1本で保持し、切端を車輪側へ出さない。CADの青い線は局所の空間確認用で、実際の配線全長・コネクタ・曲げ半径を示すものではない。

小物1個あたり2か所、計8か所を次の順で締める。小物を組む作業は荷台を外して行う。

1. 上側：M4×16ボルト、通常座金9×4.3×0.8mm。
2. 荷台：アルミ4mm。
3. PLAのφ9.4穴の中：通常座金4枚を積み、金属積層3.2mmを作る。
4. 下側：大径座金12×4.3×1mm、M4ナット。

ボルトの締付力を金属積層へ通す構成。**座金4枚の実厚を測り、PLAの実厚と合わせる。** 薄い積層を無理に締めてPLAをつぶさず、浮く場合も厚さを調整する。ねじ・ナットの強度区分、ロック方法、締付トルクは現物に合わせて確定する。

追加使用数はM4×16×8、通常M4座金40枚、大径M4座金8枚、M4ナット8個、M3ナット4個、結束バンド2本。BOMの`FIXTURE_HARDWARE`に800円の予算枠を設けたが、販売パックと実購入価格は未確定。PLA4個の約16gは既存300g消費枠に含め、二重計上しない。既存3部品を合わせた中実換算は約262gで、実印刷のサポート・パージ量はスライス後に確認する。
