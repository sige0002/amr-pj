## 切り売りの実入力と制約

横山テクノの公開自動計算へ、厚2.0mm、穴径5Φ×8P、横300mm、縦300mm、シャーリング切断、数量1を入力した。商品単価3,120円、商品重量0.32kgの表示を確認。t1.5では2,520円、0.24kgだった。過去の質問欄に載った価格からの推定ではない。

[業者の送料計算](https://www.yokoyama-techno.net/contents/simulation.php)へ300×300×2mm、0.32kg、指定済みのお届け先を入力し、税込1,000円を確認した。これはサイト自身が「概算」として表示する値で、正式な確定送料ではない。公開記録には郵便番号・町名を保存しない。注文や問い合わせ送信は行っていない。

この店は個人宛配送に対応するが、穴の方向・板端からの穴位置の指定はできない。追加加工も切断以外は受け付けない。M4ボルトはφ5穴を通せるものの、現在の50mm格子へ直接一致しない。現行のM6取付穴や荷物固定用長穴も完成済みにはならず、現物に合わせた取付方法か追加加工が必要になる。

厚2mmでも、穴なし同材・同支持の板と比べた曲げ剛性は板厚4mmの約1/8で、パンチングはさらに断面を失う。現在の荷台条件は中央200角の平底荷物、通常10kg、構造検証15kg・静的安全率2。**穴あきt2のままこの条件を満たすと判定していない。** 金属支持を増やす場合の本数、固定、費用、穴まわりの局所強度を先に決める。

## 3Dプリントとの比較

既存の[PLA上板P0](../printed-deck-concept/README.ja.md)は50mm格子・M4用通し穴を持つ4分割板で、P1Sの造形範囲に入る。

| CAD中実形状約1,072g、既存の材料仮枠2円/g | 約2,143円 |
| 追加金属支持棒用・光AS6151 995mm定尺1本 | 1,507円 |
| 材料と追加支持材の小計 | **約3,650円** |
| スリーブ、ねじ差額、送料、切断・穴加工、電力、失敗分 | 未確定 |

支持棒の[販売価格1,507円](https://store.shopping.yahoo.co.jp/akibaoo/4977720061511.html)は今回再確認した。単独購入のページには送料600円の地域表示例もあるが、お届け先・同梱条件で変わるため、小計には含めない。PLAの2円/gは新しく取得した販売価格ではなく、既存の材料費仮枠。スライスによる実消費量・長時間荷重試験は未実施で、安全率2の達成も未確認。

比較元の[JLCCNC通し穴板](../aluminum-grid-quote/README.ja.md)は300×300×厚4mm・6061-T6の一枚板で、加工28.67 USD＋表示送料9.98 USD＝38.65 USD。2026-09-21のECB公表値から算出した1 USD＝約157.2672円では、**送料込み約6,080円**（決済手数料・輸入諸費・支持材等は別）。[換算根拠](../aluminum-grid-quote/jpy_conversion.json)。元BOMの4,521円は穴加工前の板材代なので、完成穴あき板の価格として比較しない。

## 今回の判断

自分で金属板を切断・穴加工できるなら、1,526円の穴なし板に支持を追加する案を残す。ただし、材料費だけで強度や完成価格を確定しない。

加工済みの格子穴と費用を優先する場合は、**金属支持＋分割3Dプリント板**が有力。現行P0は中実約1kgを使うため、次に下げるべき費用はプリント材の量と追加支持・締結部品である。薄い表面と裏面リブに荷重を受け持たせ、支持材へ荷重を伝える形状を候補とする。これは次の設計方針であり、リブ案のCAD・スライス量・価格・強度が確定した意味ではない。低い充填率に変えるだけでP0の計算結果を流用しない。

本資料は調達比較。A6購入BOMへの採用・二重計上はしていない。
