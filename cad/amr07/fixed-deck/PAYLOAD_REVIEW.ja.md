# D6.9：固定天板の重量・荷重条件

車体推計は**10.384kg**、D6.8の10.615kgから**0.231kg減**です。取り外す部品・戻す板とボルト／ナットの体積または購入部品質量から差分を計上しました。実測重量ではなく、既存の計算機・電装等の質量枠を含みます。[差分台帳](geometry.json)

| 項目 | 今回の条件・計算結果 |
|---|---|
| 車体10kg | ユーザー方針どおり目安。厳密な上限にしない |
| 荷重計算の車体範囲 | 6〜11.5kg。上限11.5kgは現行の検討範囲 |
| 通常荷物 | 10kg、計算上の総質量最大21.5kg |
| 静的構造比較 | 荷物15kg、総質量最大26.5kg。15kg走行定格ではない |
| 荷物形状 | 中央200×200mmの連続した平底、CG前後左右±30mm、高さ330mm以下 |
| 固定天板 | 2本の上段3030上面で支持、各3本のM6で浮き・ずれを抑える |
| PLA部品 | 中実体積換算合計0.8875kg、全14個。D6.8から形状変更なし |
| 条件付き車体CG | X=−14.43〜1.45、Y=−7.76〜8.13、Z=122.96〜142.81mm |

通常10kgの積載を維持します。軽くなった分をそのまま積載増加には使っていません。積載時の荷重計算は引き続き車体11.5kgを使って比較しています。実装する計算機、配線、追加センサ・ロボットアームは実重量と重心へ算入し、範囲を超える場合に再計算します。

## 天板と固定部

下向き荷重をレールで受ける構成なので、ヒンジ保持モーメントの計算は不要になりました。追加の金属L金具や樹脂の持ち出し部分もありません。6本のM6はボルト頭から板を直接締め、2本の3030上面へ押さえます。

板の傾向を見る簡易計算として、幅の50%に相当する有効幅150mm、支持間240mm、板厚4mmの単純支持梁に、中央集中荷重15kg×g×2=294.20Nを与えると、曲げ応力44.13MPa、たわみ1.535mmです。E=69GPaを仮定しています。これは穴付き板そのものの有限要素解析ではなく、有効幅の仮定を含む比較計算です。板自重・荷締め張力・局所穴応力・締付接触・支持レールの変形を含めた最終判定には使いません。

旧D3は同じ製造形状ですが支持条件が異なります。旧D3の解析結果だけで今回の2本支持を認定しません。素材は6061-T6・耐力240MPa以上を調達条件にしていますが、実品材質、溝ナットの引抜き、締付、局所変形、積載保持試験は未確認です。**15kg・安全率2は検証条件であり、車体全体で達成済みとはしていません。**

## 駆動系と操作箱

平地・通常荷物10kg・総質量21.5kgの計算で、各輪の必要トルクは0.2675N·m、1.5倍の選定余裕込み0.4012N·mです。既存の仕様記録の定格0.96N·mと比較する条件を維持します。低速連続運転・電圧低下・熱・停止距離は実機試験前です。

同じ車体質量・CG範囲で、通常ケースのモーター半径方向比較荷重は100.91N、静的15kg比較では119.32N。記録上のカタログ120Nに対して後者の余裕は小さいため、積載増加や段差衝撃へ適用しません。[全ケース・キャスター偏心感度](payload_budget.json)

床支持の非常停止・主電源箱と4点固定は形状変更なしです。既存の押下力120N・荷重係数2の比較では、PLA蓋リブ14.2MPa、床の一体支持部12.32MPa。印刷試験片25MPa以上という要求に対する比較であり、実印刷材の強度・クリープ・240N押下試験を完了したものではありません。

## 今回実施した幾何検査

変更部を含む静的4,186組と機器外形を検査し、干渉なし。電池・計算機を天板付きで抜く経路、天板を120mm上へ外す経路、6本の天板ボルトと8本のケース固定ボルトの工具経路、非常停止・ARM・主電源への接近を確認しました。直線移動は部品ごとの連続した掃引包絡箱で比較しています。配線は経路予約で、実際のケーブルの変形・曲げ寿命の確認は別です。

保存FCStdから出力したSTEPの閉じたソリッド数・体積、製造天板と見積STEP、既存14個のPLAのSTL体積を照合済みです。[検査結果](validation.json) ／ [保存物との照合](saved_artifact_validation.json)
