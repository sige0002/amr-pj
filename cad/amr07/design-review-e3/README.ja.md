# E3レビューとE4での対応

ユーザー依頼により、機構設計とロボット/電装の独立AI担当へレビューを依頼し、両報告を受領後にE4を作成した。人間専門家への外部発注や認証ではない。

- [機構設計レビュー](MECHANICAL_REVIEW.ja.md)
- [ロボット・電装レビュー](ROBOTICS_REVIEW.ja.md)
- [変更天板の強度・締結再レビュー](DECK_REVISION_CHECK.ja.md)
- [E4の再確認](ROBOTICS_RECHECK.ja.md)
- [修正版E4](../reviewed-design/README.ja.md)

| 指摘 | 対応 | 状態 |
|---|---|---|
| M-01/R1：ナット・工具・配線保持 | ナットと端末確保空間を追加、主電源リブ逃げ/補強環、箱内結束橋、電池を外す組立手順 | 公称CAD対応。主電源実寸・端末・配線は未確定 |
| M-02/R6：突出した固定部と常設ストッパ | 外周6点へ移動、頭高さ1.5mm、ストッパは標準撤去。250角の荷物例を確認 | CAD対応。低頭ねじの実締付・実荷重試験は未実施 |
| M-03/R5：穴の非対称/裏工具制約 | 中央原点50mmピッチ25穴、全穴同じ貫通締結。長穴対称化 | 電池外しで全25穴工具クリア。装着時3穴制約を明記 |
| R4：操作空間 | 上からの押下/解除と後ろからの接近を確認、表示を指定 | CAD包絡確認。実機操作性は未確認 |
| M-04：PLA締付クリープ | 押下と持続締付を分離し、試験条件/未確認を明記 | 未解消、実印刷試験が必要 |
| R2：電装負荷適合 | NC各1モーターを維持、実突入/最細線/ヒューズを確認項目化 | 未解消、通電前の条件 |
| R3：停止後の復帰 | 古い指令破棄、片輪異常で両輪禁止、ゼロ再接続と明示RUNを仕様追加 | FW未実装・未試験。短断電の検出保証なし |
| R7：完成ハーネス | 各系統の既製品/端末加工調達方針を表にした | 型式・線径・端末・長さの確定が残る |
| 新形状の加工価格 | 旧天板見積を現行BOMから除外 | 新STEPの実再見積待ち |

標準にモニター・産業用安全コントローラー・二重リレー・専用ARMを追加しない。スイッチ箱統合は電池サービス口を塞ぐため採用しない。皿M6は板の残肉と追加加工を避け、極低頭品を選んだ。

寸法照合の追補：公開済みの3214外形とHW取付図を再照合し、仮円柱・接点包絡・回り止めを訂正。[根拠と未確定項目の分類](../reviewed-design/SWITCH-DIMENSIONS.ja.md)。元のレビュー報告は受領時の記録として保持する。
