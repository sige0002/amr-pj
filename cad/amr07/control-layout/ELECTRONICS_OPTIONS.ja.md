# 手持ちPicoを使う制御・電源保護の比較

**手持ちPico＋既製5V DC/DCを使い、保護・通信部分を小さな専用基板へまとめ、細かい実装を外注する構成を推奨する。** 既製モジュールで通信・リレーを組む方法も比較したが、それだけでは独立監視、再始動防止、低電圧保護、回生処理が完成しない。専用基板の完成価格は未見積であり、最安と確定したわけではない。

Pico本体は所有申告により購入費0円とした。初代／H／W／2などの型番、ピン実装、USB線の所有は未確認。旧Pico Hの920円だけを除外し、基板や配線まで所有とは仮定しない。型番確定後にピン割当・電源入力・ヘッダー高さを決める。

## 同じ役割を比較する

| 方法 | 確認できた費用 | 自分で行う作業 | 配置・制約 |
|---|---:|---|---|
| 部品から専用基板を作り手実装 | 既存RS485 IC70＋リレー2個770＋5V DC/DC850＝**1,690円** | 基板製作、はんだ付け、配線、検査。回路設計も別途必要 | 一体化しやすいが、これは3機能分の部品代だけ |
| 小型モジュールを組み合わせる | AmazonのPico用RS485候補1,900＋リレーキット2枚1,200＋DC/DC850＝**3,950円** | リレーと端子台のはんだ付け、モジュール間配線、保護回路追加 | リレー基板だけで54×30mmを2枚。70×70mm予約枠へ端子余裕込みで収まるか再設計が必要 |
| Pico用8chリレー基板を使う | リレー基板3,476＋RS485候補1,900＋DC/DC850＝**6,226円** | 配線と独立保護回路追加 | 145×90mm・243g。必要なリレー2個に対して大きく、現在の予約枠に入らない |
| 専用基板を製造・実装外注 | **総額未見積**。下記の公式実装料金を確認 | 回路・基板設計、製造データ作成、受入試験、ハーネス組立 | 細かいICを手ではんだ付けする負担を減らせる。設計・検証は依然必要 |

3,950円−1,690円＝2,260円は**通信・リレー・5V電源だけ**の差。保護回路全体の差額ではない。上表はいずれもE-stop、主スイッチ、ARM、独立低電圧保護、回生クランプ、外部WD、端子、ヒューズ、ケース、送料を揃えた完成品価格ではない。

出典：[M78AR05-1・850円](https://akizukidenshi.com/catalog/g/g113536/)、[AE-RELAY953B-5V・600円/キット](https://akizukidenshi.com/catalog/g/g111245/)、[Pico-Relay-B・3,476円](https://www.switch-science.com/products/7546)、[Amazon RS485候補・1,900円](https://www.amazon.co.jp/dp/B0GKHKCZV3)。確認日は2026-09-23。

RS485候補はSP3485・3.3V系の販売表示を確認したが、1,900円の出品をWaveshare正規品と断定しない。[Waveshare公式仕様](https://www.waveshare.com/wiki/Pico-2CH-RS485)は52.5×21mm、Pico用2ch。国内正規販売の[スイッチサイエンス](https://www.switch-science.com/products/7548)は1,287円だが確認時売切れ。同じ2chでも出品者・基板改訂・電源接続を受入確認する。左右モーターを別IDの1本のバスへ接続すれば1chで足りる。

リレーキットはドライバ部実装済みでも、リレー・端子台のはんだ付けが必要。接点のDC負荷・突入適合も確認が必要で、「30A」という商品名だけで既存G5LEの代替にしない。

## 既製モジュールで置換しきれなかった機能

| 機能 | 調べた候補 | 今回の判断 |
|---|---|---|
| 全負荷の低電圧遮断 | [CZH-LABS D-1021V3 18V30A、22 USD](https://czh-labs.com/products/czh-labs-low-voltage-disconnect-module-lvd-18v-30a-protect-prolong-battery-life) | 商品説明では低電圧／復帰とも5秒遅延、自動再投入あり。16.5V遮断・18V復帰可能＋手動ARMという現行要件との一致は未確認 |
| 回生吸収 | [Pololuシャントレギュレータ](https://www.pololu.com/category/249/shunt-regulators) | 短時間パルス用というメーカー条件と、今回の約10J・0.5秒試験が一致しない。固定26.4V型もモータ端24V未満の要件に合わない。単純置換しない |
| 外部監視＋手動再許可 | Pico内蔵WD、一般リレーボード、周期電源タイマーなど | Pico停止時にも遮断し、故障復帰だけでは再投入しない仕組みを、今回確認した安価な1枚で置換できていない |

これらは必要機能が全部存在しないという主張ではなく、今回比較した候補の判定。運転条件と[保護回路案](../ELECTRICAL_AND_VALIDATION.ja.md)を揃えて評価する。非常停止はPicoのソフト処理を待たず、2NC接点で2個のリレーコイルを切る構想を維持する。

## JLCPCBの公式実装料金を使った比較

2026-09-23に確認した[公式料金表](https://jlcpcb.com/help/article/pcb-assembly-price)（2026-09-09更新）のEconomic PCBAを使用する。

| 料金項目 | 公式表示 |
|---|---:|
| セットアップ／注文 | 8.18 USD |
| ステンシル | 1.53 USD |
| SMT実装 | 0.0016 USD/接合点 |
| 手実装 | 0.0164 USD/接合点 |
| 手はんだ作業の固定費（発生時） | 3.58 USD/注文 |
| Extended部品のフィーダー | 3.07 USD/種類 |
| 任意の配置確認 | 0.45 USD |

基板代、部品代、送料、税、為替手数料は別。複数設計の面付けをしないのに8.21 USDの面付け料を必ず足す、といった計算はしない。最低実装数量は[公式能力表](https://jlcpcb.com/capabilities/pcb-assembly-capabilities)で2枚。注文単位の固定費を1台分へ按分して、支払額と混同しない。

記録済み参考為替157.2672円/USD（2026-09-21）なら、セットアップ＋ステンシル＋手はんだ固定費は13.29 USD≒2,090円。Extended部品が5種類なら、この部分は28.64 USD≒4,504円、10種類なら43.99 USD≒6,918円になる。**これは料金表の感度計算で、AMR用基板の実見積ではない。** Gerber・製造BOM・CPLが未作成なので、製造サイトへ設計データを投入した完成価格は取得していない。基板設計後に数量・部品在庫・送料を揃え、実際の見積で決める。

## CADとBOMへの反映範囲

後方E-stop、手動ARM、主スイッチは型式・取付ケース・固定位置をCADへ反映済み。前方1階にある70×70×35mmの保護回路枠と、70×45×30mmのPico／通信枠は、**回路基板の完成形ではなく予約容積**。商品未確定の計算機、実装基板、端子配線は未計上として残す。

制御・保護の既計上電気部品は、USB線500円を含め**8,475円**（Pico0、E-stop3,153、主電源621、ARM835等）。後方ケース用座金968円を同カテゴリに含めたBOM表示は9,443円。どちらも完成電装費ではない。専用PCBA案へ決定した段階で裸ICの購入行を製造BOMへ移し、二重に買わない。
