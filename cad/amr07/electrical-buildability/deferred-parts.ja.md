# E2：初回購入の必須から外した部品

この表は購入指示ではない。条件付き項目は必要性を確認してから追加する。旧価格は履歴で、今の見積ではない。

[最小構成](README.ja.md) ／ [現行BOM](../fixed-deck/BOM.ja.md) ／ [CSV](deferred-parts.csv)

| ID | 部品 | 段階 | 理由 |
|---|---|---|---|
| ELEC_U1 | 手持ちRaspberry Pi Pico | 後工程 | 手持ち品として保持。初回USB–RS485接続には不要。ローカル制御が必要になった時に使用。 |
| U01 | 完成済みの電池保護・全負荷低電圧遮断 | 条件付き | 電池・アダプターの既存保護を確認し、不足があれば追加。未確認のまま不要とは断定しない。 |
| U03 | 上位計算機・記憶媒体・冷却 | 後工程 | 初回は操作用PCを外部接続。車載PCは単独走行が必要になった時に選定。 |
| U04 | 上位計算機用DC/DC | 後工程 | 車載PCの採用時のみ。初回の通信はUSB給電を基本とする。 |
| U09 | 駆動遮断・コイル保護の完成済みユニット | 条件付き | 非常停止ボタンのDC接点で直接切れない場合のみリレー1個とソケット／完成品を選定。 |
| U10 | 手動再許可・独立監視の完成済みユニット | 初回不採用 | 専用再許可回路・独立監視ユニットは初回必須にしない。 |
| U11 | 回生吸収・逆流保護の完成済みユニット | 条件付き | 減速・遮断時の電源適合性を確認し、必要な場合だけ対策する。旧自作クランプを採用しない。 |
| U12 | 電圧・電流・温度監視の完成済みモジュール | 後工程 | 車載の追加監視センサー一式を先に購入しない。 |
| U14 | 放熱固定具・ガード・絶縁材 | 条件付き | 回生抵抗など発熱部品を実際に採用する場合のみ。端子絶縁はU15に含む。 |
| U19 | 自律移動用LiDAR・IMU・カメラ等 | 後工程 | 最初は手動走行。自律移動に着手する際に選定。 |
| ELEC_ARM | 手動ARMボタン（黒） | 初回不採用 | 専用ARM回路と追加ボタンを設けない。 |
| ELEC_MAIN | 全電源の主スイッチ | 初回不採用 | 非常停止用遮断と着脱コネクタに加えた別の主スイッチを必須にしない。 |
| U21 | 制御系の完成済みDC/DC・給電ケーブル | 条件付き | USB給電で不足する機器やリレーコイルを採用する場合のみ。 |
| U23 | 必要なハーネス製作・組立検査費 | 条件付き | 既製配線で接続できない部分が判明した場合のみ加工費を調べる。 |

このうち旧計上価格は計1,456円。代替部品の未計上分があるため完成車の節約額ではない。
