# 最初に動かすための電装（E3）

**車載LinuxミニPC → USB → 手持ちPico → 完成済み2CH RS485基板 → 左右M0601C_111** を現行構成とする。まず手動で前後進・旋回・停止でき、非常停止でモーター電源を切れる構成を作る。自作PCB・裸ICからの回路組立・ユーザーのはんだ付けは前提にしない。

[配置・CAD画像](../pico-control/README.ja.md) ／ [配線構成](../pico-control/WIRING.ja.md) ／ [要件JSON](requirements.json) ／ [BOM](../fixed-deck/BOM.ja.md)

| 部品・機能 | 現行の扱いと用途 |
|---|---|
| 手持ちPico＋2CH RS485 HAT | USB指令を左右のUART–RS485へ渡す。専用ファームウェアは未実装 |
| 別体USB–RS485変換器 | Pico/HAT構成では購入しない |
| 外付けモータードライバー | M0601C_111が内蔵しているため購入しない |
| 非常停止HW1B-V402R | 2NCの一方で左、もう一方で右の電源を直接切る選定案。ねじ端子、突入適合は未確認 |
| 主電源amon3214 | 計算機を含む全電源の操作用として残す。非常停止とは用途が異なる |
| 電源・分岐ヒューズ | 線材と負荷の保護。特性・線径・コネクタに合わせた最終型番は未確定 |
| 二重リレー・溶着診断 | 旧案の遮断冗長化・故障監視用。初回構成には追加しない |
| 外部ウォッチドッグ・ARMラッチ・専用ARMボタン | 旧案の通信監視・再始動許可用。初回構成には追加しない |
| 低電圧遮断・回生対策 | 不要と証明したわけではない。既存保護と実機電圧を確認してから必要な対策を選ぶ |
| 車載計算機と給電部材 | LinuxミニPCを搭載。Pi 5固定ではなく、機種・価格・実品外形は未選定 |

電源は電池→主ヒューズ→主電源の後で左右モーターと計算機へ分岐する。非常停止時もPC/Picoは給電を維持する。0V帰路、通信ピン割当、分岐は[配線構成](../pico-control/WIRING.ja.md)に示した。現物端子番号・ハーネス型番・線長まで確定した製作配線表は未完。

内蔵電気ブレーキは速度モードの0x64指令DATA[7]=0xFFを使う機能で、通電した制御が必要。非常停止による電源断後の制動・坂道保持は保証しない。対象は平坦な屋内床。独立した安全監視・再始動防止機能を備える構成とは扱わない。[メーカー説明書](https://d2air1d4eqhwg2.cloudfront.net/media/files/a48110eb-432c-4083-a159-9e0f35913b23.pdf)

E3 CADでは旧ARM・旧非常停止・不要な電装予約容積を撤去し、ねじ端子非常停止用ケースとPicoケースを反映した。基板積層高さとコネクタは仮形状のため、現物で仮合わせする。手持ちPicoのヘッダー状態とAmazon HATの価格・回路改訂は未確認。

[撤回した旧回路部品6,519円](withdrawn-parts.ja.md)と[今は購入しない部品](deferred-parts.ja.md)は現行購入BOMから分離した。主電源621円は購入対象へ戻し、ARM835円は外したまま。新しい非常停止2,387円＋表示送料780円を計上したが、未計上品があるため差額を完成車の節約額とはしない。
