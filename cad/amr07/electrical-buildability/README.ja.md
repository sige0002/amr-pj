## 組み立てられる構成の条件

完成済みモジュール、接続済み端子台、端末加工済みケーブルを優先する。ユーザーによる基板製作・はんだ付けを前提にしない。圧着工具の所有も仮定せず、専用の端末加工が必要なら既製ハーネスまたは製作・導通検査まで含めた外注を比較する。基板だけを実装外注し、残りの配線加工をユーザーへ戻す構成では条件を満たさない。

こちらで型式・電源仕様・端子番号・線径・線長・接続先まで設計し、配線図と購入表を揃える。ユーザー側の製作作業は、設計済み部品の機械固定と指定コネクタ／端子への接続を基本にする。実機検査は別工程として必要な作業・道具・外注範囲を明示する。現時点では、この一式は未完成である。

| 対象 | 今回の訂正 | 残る設計 |
|---|---|---|
| 制御・保護の専用基板 | 製作を前提にした採用を撤回 | 完成済みモジュールで必要機能が成立する構成を選ぶ |
| 裸のIC・基板実装用リレー等 | 11明細を現行購入BOMから外し、価格履歴へ移す | 同じ機能を担う完成品と配線費を計上する |
| 非常停止 XA1E-BV302R | はんだ端子のため、未加工品をそのまま買う案を撤回 | 2NCのねじ／適合コネクタ端子品か、配線加工済み品を選定し、箱へ再配置する |
| 主電源 amon3214 | 型式とCAD配置は候補として保持 | 指定250型メス端子の加工済み線、電流・突入適合を確定する |
| ARM amon3212 | 操作位置の候補を保持 | 完成済み許可回路との接続・接点負荷・ケーブルを確定する |
| 手持ちPico | 所有分の購入費0円は維持 | 型番・ヘッダーの状態に合わせる。ヘッダーなし品のはんだ付けを要求しない |

非常停止をソフトウェア処理だけへ変更する、復電だけで走行を再開する、電池保護や回生処理を省略する、という代替にはしない。一方、旧案で選んだIC、2個のG5LE、個々の定数をそのまま新構成へ強制するものでもない。必要な動作を満たす完成品構成として再評価する。

旧購入候補から、専用回路の11明細3,366円と、はんだ端子の非常停止1明細3,153円を移した。計6,519円の旧表示価格は[履歴CSV](withdrawn-parts.csv)に保持した。**これは節約額ではない。代替完成品・ハーネス・必要な組立検査の価格がまだ入っていないため、小計が下がる。** 新しい電装一式と完成車総額は未見積である。

D6.9の機械形状は今回変更していない。図に残るXA1E-BV302Rは撤回済み型番の配置参考であり、購入指定ではない。電装の直方体は予約容積にすぎず、新しい完成品の寸法・配線を入れた干渉検査は未実施。既存の機械CAD検査を電装の完成証明に使わない。電装質量も既存の予約値のままで、部品を購入表から外した分を軽量化とは計上しない。

完成させる対象は、部品表だけでなく、端子番号入り配線図、ケーブル明細、総費用、実部品のCAD配置、組立・検査手順である。今回完了したのは製作条件と購入表の訂正であり、代替電装の設計完了や動作確認ではない。
