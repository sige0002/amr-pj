# P1天板の継ぎ目レビュー

2026-09-22。ユーザーの「継ぎ目は固定できているか」という指摘を受け、保存済みCADの4枚の板、8本の固定ねじ、隣接面の距離を確認した。[実形状からの確認記録](seam_review.json)。このレビューでは形状を修正していない。

**各板をフレームへ留める固定点はあるが、継ぎ目の支持・連結設計は未解決。現状を完成した荷台として扱えない。**

| 確認項目 | CADの状態 | 評価 |
|---|---|---|
| 板からフレームへの固定 | 各板M6×2本。2本とも同じ上段3030上の一直線に配置 | 板端の荷重・浮上りに対する固定部の剛性検証が必要 |
| 隣接板のつなぎ | 隣接4組とも最短距離0.4mmの突き合わせ | 相じゃくり・ほぞ・裏面連結板・継ぎ目用ボルトはない |
| X=37.5の継ぎ目 | 直下に上段支持材がない | 左側の板端は支持材端から132.3mm、右側は22.3mm張り出す。荷重時の相対段差を確認できていない |
| Y=37.5の継ぎ目 | 上段3030の2本と交差する部分で支持 | 継ぎ目全長を連続支持する構造ではない |
| 既存の検査 | 公称形状干渉、穴位置、ねじ・工具包絡と整備経路を確認 | 継ぎ目の変形・締結部の剛性・長期クリープ・15kg/SF2を検証した結果ではない |

分割板は、それぞれに適切な支持があれば板同士を直接つながない構成も成立し得る。P1については、支持位置から離れた継ぎ目の変形と、一本の支持材に留めた板の荷重伝達を評価できていないため、その条件が成立したとはいえない。

修正では、隣り合う板端から骨格へ荷重を伝える経路を設ける。候補は継ぎ目と支持材の配置を合わせる構成、またはボルトで留める裏面連結材を設けてその曲げ・締結も評価する構成。単に接合用の突起を印刷するだけで耐荷重を認めない。

検討条件は、格子穴36か所へのアクセス、天板を外した電池整備、荷台高さ、車体10kg以下、金属支持材の自家切断・穴加工なし、購入単位での費用。修正形状の支持・接合部を含む変形と強度を確認するまで、P1の荷重使用は未承認のままとする。
