**A3 DDSM115の初期費用とA2との差分 — 2026-09-20**

現行CADに合わせた予算は、**自加工47,824円、外注加工の追加仮枠を含め53,824円**。A2の全費目を対応付け、新マウント、USB通信、ケーブル、追加PLA・締結材も計上した。走行余裕を優先した選択に基づきDDSM115のCADを作成した後、ユーザーは**摩耗したゴムだけを交換でき、適合補修品を個人で買えること**を優先要件に追加した。DDSM115のCADは比較候補として保存し、補修調達確認前に購入仕様を確定しない。[選定記録](MOTOR_COMPARISON.ja.md)、[タイヤの確認結果](TIRE_WEAR.ja.md)

[BOM](BOM.csv)の元データは[bom.json](bom.json)。[費用集計](cost_summary.json)は`python3 cad/amr04/calculate_cost.py`で再生成でき、A2の全18購入行とA3の全16購入行を重複なく比較する。以下は税込の計画予算で、発注額・加工見積ではない。

| 費用の区分 | A2参考予算 | A3現行予算 | 差額 |
| --- | ---: | ---: | ---: |
| 部品・素材・消費材 | 30,169円 | 45,014円 | ＋14,845円 |
| 部材配送 | 4,350円 | 2,810円 | −1,540円 |
| **自加工の購入予算** | **34,519円** | **47,824円** | **＋13,305円** |
| 外注加工の追加仮枠 | 6,000円 | 6,000円 | 0円 |
| **外注加工を含む予算** | **40,519円** | **53,824円** | **＋13,305円** |
| 自加工・10%予備費込み | 37,971円 | 52,607円 | ＋14,636円 |
| 外注加工・10%予備費込み | 44,571円 | 59,207円 | ＋14,636円 |

自加工と外注は条件の異なる二つの計算で、この間に実費が収まる保証ではない。10%予備費は別表示し、通常合計へ重ねて加算しない。自加工では既所有工具と自己作業を前提とし、新規工具代・作業時間・印刷電気代を含めていない。PLAのみ既所有材の消費分で、他の購入部品は予備を含む購入単位全体を計上する。

電池・主計算機・センサー・電源変換／保護・非常停止・車内電源／RS485配線・コネクター・終端部品・完成用ガード等は、両案とも別の未選定・未見積費用。電池の予約空間や電装の質量枠は価格を計上した意味ではなく、未選定を無料とは扱わない。

**初期費用の増減理由**

| 変更項目 | A2からA3への差額 | 集計内容 |
| --- | ---: | --- |
| 駆動部品 | ＋7,945円 | FIT0185、タイヤ／ホイール、ハブ、車軸、KP08、カップリング、カラーの合計18,037円を撤去し、DDSM115を25,982円で計上 |
| USB-RS485B | ＋4,400円 | 通信インターフェース1個。主計算機は含まない |
| USBケーブル | ＋500円 | 別売のため仮枠を新設。端子・長さ・商品は未選定 |
| 金属素材 | ＋1,600円 | 旧2,600円を新4,200円へ置換 |
| PLA消費分 | ＋100円 | 前部トレイを追加し、500円から600円へ |
| 一般締結材 | ＋300円 | 2,000円から2,300円へ。購入パックは未見積 |
| 配送 | −1,540円 | DigiKey専用枠2,200円を撤去、エレファイン660円を追加 |
| **合計** | **＋13,305円** | 共通フレーム・純正接合部・キャスター・ストラップは同額 |

採用前の40,264円は、旧素材・締結材を据え置いた比較途中の値だった。そこへUSB通信・送料のみを加えた45,324円も履歴値である。現行額はさらにUSBケーブル500円、素材差1,600円、PLA差100円、締結材差300円を加えた**47,824円**へ更新した。

A2の34,519円には別体モータードライバーと速度制御MCUが含まれていない。一方、A3はドライバー内蔵のDDSM115とUSB通信を含むので、13,305円を同じ完成機能での最終差額とはしない。A2に比較用品の[MDD10A](https://www.elefine.jp/SHOP/MDD10A.html)3,630円と通常送料660円を足すと38,809円で、A3との差は9,015円となるが、A2のPWM・エンコーダ読取・速度制御MCU等はなお別途必要。これは追加部品を明示するための中間比較で、MDD10AをA3のBOMに重複計上しない。

**購入価格と未見積部分**

[DDSM115の商品9628](https://www.switch-science.com/products/9628)は確認時12,991円／個、在庫表示3個。2個で25,982円、タイヤとドライバーを含む。[同店の標準配送規定](https://www.switch-science.com/policies/shipping-policy)の8,000円以上の送料無料条件を適用し、送料は0円とした。商品ページの送料区分650円を重ねて加算しない。未発注・在庫未確保で、価格・在庫・配送条件は注文時の確認が必要。

[USB-RS485B](https://www.elefine.jp/SHOP/USB-RS485.html)は確認時4,400円、在庫わずか表示。[通常送料660円](https://www.elefine.jp/hpgen/HPB/shop/business.html)とUSBケーブル500円枠を合わせて**5,560円**を計上した。これは国内の在庫品を用いた予算選定で最安価格の主張ではない。実機通信・終端・配線とソフトウェアは未検証。

純正[HBLFSN6-SET](https://jp.misumi-ec.com/vona2/detail/110300442340/)8組の1,540円は、2026年7月公式表の本体78円＋SET97円、税別175円／組を税込換算した参考値。個人購入経路・請求単価・送料は未確定。[追加HNTT6-6](https://jp.misumi-ec.com/vona2/detail/110302610850/)28個は1,200円仮枠で、実在する28個入り商品の確認価格ではない。300／400mmのAmazon定尺フレームとキャスターは、2026-09-20付A2の価格記録を引き継いだ。

部品小計45,014円のうち、今回確認した販売価格が30,382円、A2から引き継いだ販売価格が3,792円、公式表の参考換算が1,540円、素材・小物等の仮枠が9,300円。いずれも購入前である。配送2,810円にはキャスター650円、素材等1,000円、純正金具500円、USB通信660円を含み、素材の発注先が分かれれば更新する。

外注6,000円は旧案と同額の仮枠にすぎない。旧車軸の平面加工、ハブ穴加工、KP08支持板が不要になる一方、今回の角材脚切詰め、局所逃げ、キー異形輪郭、ケーブル孔／導入溝、取付孔、バリ取りが必要になる。加工精度・工具アクセスと外注配送を含む見積を取得して更新する。素材代4,200円を加工枠へ二重計上しない。

[締結部品表](fasteners.csv)と照合し、溝ナット44個＝SET付属16＋追加28、SET付属以外の一般締結材102点を確認した。上マウント用の溝ナットは4個、追加した前部トレイ用も4個で、A2から総数は変わらない。一般締結材2,300円はM2.5×10を6本などの使用数を含む仮枠であり、販売パック全体の価格は未見積。

初期BOMにタイヤ等の寿命費は含めていない。[公式のゴム脱着手順](https://www.waveshare.com/wiki/DDSM115#Installation_Guide)は確認できたが、DDSM115に適合するタイヤ単体のSKU・価格・供給期間は未確認。DDT M0601C_111用タイヤ4,620円は互換未確認のため選定BOMへ追加しない。単体調達できない場合は、現在のユニット価格**12,991円／輪、左右25,982円**を基点に交換費を含めて他方式と再比較する。将来価格・供給や交換周期を保証する値ではなく、工賃・廃棄費も未見積である。

[交換回数別の費用比較](maintenance_costs.json)では、モーターとタイヤの左右2輪分だけを比べると、DDSM115のユニット交換を仮定した初回／左右1回交換後／2回交換後は25,982／51,964／77,946円。適合タイヤキットが明示されたDDT M0601C_111は38,060／47,300／56,540円となる。ただしDDT本体は売切れで、今すぐ購入できる代替案ではない。寿命や同じ期間内の交換回数が等しいとは仮定しておらず、この部分比較を台車全体の累計額と混同しない。DDSM115のタイヤ単体価格は未確認のまま残す。
