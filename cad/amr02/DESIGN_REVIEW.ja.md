# 第二案 B：設計判断と検証条件

2026-09-20。第二案の[設計パラメータ](design_parameters.json)と併読する判断記録。**第二案の比較試作としてCAD化した構成は、低い同軸駆動＋車輪を内外の軸受で挟む金属箱形支持。3030の高さと車軸の前後位置を維持し、第一案の40mm丸スペーサ8個を撤去する。** 機械構造を比較する段階であり、現物部品の荷重定格や完成機の連続運転性能は今後の検証対象となる。

この判断には三担当が参加した。各担当が第一案の資料を別々に調べ、その後に配置案・計算・懸念点を交換している。独立した検討過程は以下に残す。

| 担当・記録 | 当初の提案・指摘 | 統合案への反映 |
|---|---|---|
| [車輪支持担当](../../docs/reviews/wheel-module-review.ja.md) | 車輪の張出しを減らし、軸受反力とフレームへの荷重経路を改善 | 内外KFL08、前後ウェブ、二本の長手材への固定、脱着式外壁 |
| [上置き駆動担当](../../docs/reviews/top-drive-review.ja.md) | 上置きベルトの具体配置を検討。モーター出力へのベルト直掛けと干渉を指摘 | 上置きは別支持の上軸を含む比較案にする。追加費と調整作業を明示 |
| [要求・費用担当](../../docs/reviews/requirements-review.ja.md) | 調達条件と費用を維持し、高さ・輪距・キャスターを同時変更する代償を指摘 | 高さ75〜105mmと50mmキャスターを維持。幅拡大と輪距縮小は明示して比較 |

三担当が一致した点は、**箱形支持による改善をモーター上置きの効果として扱わないこと**、3030を全面的に大型化する前に接合部と車輪支持を改善すること、10kgを上限として実際の質量を別に積み上げることである。上置きの整備性には利点があり、配置上の必要性が生じれば再評価する。

| 要求の区分 | 条件と第二案の対応 | 対応する検証 |
|---|---|---|
| 必須：購入材 | Amazonで個人購入できる3030の300/400mm定尺を使い、外寸460×300mm。400mm×4、300mm×2を無切断で組む | BOM、現物型番、フレーム外寸。板材・軸の加工費も計上 |
| 必須：質量管理 | 台車は電池・電装込み10kg以下。荷物2kg、将来アーム系2kgは別枠、最大構成14kgで計算 | 部品積上げと完成時の計量。取付板・専用電源等の計上漏れ確認 |
| 必須：費用と目的 | 費用を重視し、意匠用外装は追加しない。局所ガードと構造板は残す | 第一案と同範囲の購入総額・加工費・送料、機能部品の質量を比較 |
| 第二案の固定条件 | フレームz=75〜105、駆動軸x=90/z=50mm、100mm車輪、同軸駆動、50mm後方キャスター | 公称CAD干渉、回転包絡、固定部の最低地上高、工具の進入 |
| 優先する選択 | ミスミ純正6シリーズ接合部、主荷重経路は金属。P1SとPLAを治具・機器トレイ等へ使用 | 純正部品の個人購入経路、現物適合、樹脂部品の温度・変形 |
| 軟らかい外形目標 | ガード込み500×420×高さ180mm。従来の幅400mmから変更 | 公差・ねじ・ガードを含む包絡、家の通路・収納・旋回空間の実測照合 |
| 未確定 | 電池・計算機、床の段差、アーム機種・姿勢・把持質量、加工見積 | 部品選定と現物計測後に重心・支持領域・運転条件を再計算 |

10kgは完成時にその質量が存在するという意味ではない。安定性に10kgの復元力を用いる前に実際の質量・重心を確認する。上限までの余裕をバラストや外装で埋める要求もない。荷物2kgの運搬要求は、アームが2kgを持ち上げられるという要求ではない。

第一案は軸受中心y=118/145mm、車輪中心177mmで、車輪が外側軸受から32mm張り出す。第二案は軸受中心115/192mm、車輪中心170mmとする。剛な単純支持・車輪中央100Nの鉛直集中荷重という比較条件では、軸受反力は第一案の約−119/+219Nから約28.6/71.4Nへ、8mm軸の最大曲げ応力は約63.7から31.3MPaへ下がる。**100Nは配置比較用の仮定であり、定格輪荷重・必要試験荷重・段差衝撃係数ではない。** 軸受・板・締結部の変形や疲労を含む結果ではない。

第二案の荷重経路は、タイヤ→ハブ→8mm車輪軸→内外KFL08→金属内外壁→上板・前後ウェブ→3030へつなぐ。内壁y=105〜109、外壁198〜202、上板z=105〜109mmを基準とする。上板は内側レール中心y=65と外側レール135の双方へ固定し、前後ウェブでも箱を閉じ、3030側面へ固定する。外側軸受がレール外にあるため、局所的な偏心荷重と接合部のねじりは残り、二面締結だけでねじりが消えるとは扱わない。右側は鏡像配置とする。

外壁はボルトで脱着し、交換時に車輪・カラー・外側軸受へアクセスできる構成にする。運転時には外壁を含めて箱として働かせる。KFL08の型名だけでは、取付穴間隔、厚さ、内輪長さ、許容荷重まで一致したとはいえない。採用販売品の現物に合わせて壁の穴・軸方向保持・シャフトの差込長を確定する。

幅と支持領域には代償がある。外壁端だけで幅404mmとなり、ガード等を含めて幅420mmを目標とする。輪距は354から340mmへ狭まるので、支持三角形を更新する。タイヤ内側157.3mmと側面金具外端153mmの公称隙間は4.3mm（3030外端150mmまでは7.3mm）。金具の水平脚を車輪上方で切り欠き、タイヤ上端と上板の隙間5mmを確保する。実タイヤの幅・振れ・変形、組付け誤差、ねじ頭とガードまで含めて成立させる。

| 比較案 | 利点 | 代償・未解決点 | 採否 |
|---|---|---|---|
| 第一案を箱で補強し、従来の片持ち車輪を維持 | 改変部品を抑え、スペーサ支持を改善できる | 車輪の32mm張出しと軸受反力の増幅が残る | 最小費用の比較基準 |
| **低い同軸＋内外軸受の箱形支持** | 支持反力と軸曲げを低減。モーター・車輪・同軸継手の候補を活用できる | 新規箱板、KFL08、芯合わせ、幅420mmと輪距340mmの評価が必要 | **主案** |
| 高さ125mm／輪距302mmの初期案 | 車輪上方へフレームを逃がし、内外支持を組みやすい | フレームを50mm上げ、重心・機器配置・キャスター台座を変える。輪距も大きく縮む | 支持改善に変更を絞るため見送り |
| 上置き＋独立支持軸＋ベルト | 床付近のモーターを移せ、上から整備しやすい | 追加部品・支持台加工・張力調整・ガード。低位置案より0.8〜1.5万円の未見積増額枠 | 必要性が確認された場合の代替案 |

初期の高さ125mm案は、3030を低いまま輪中心y=151mmへ置くとタイヤがフレームへ干渉する問題を、高さ変更で解く候補だった。ただし高さ65mmの既存キャスターを同じまま使うには支持台座も再設計する必要があり、高さ180mmの機器配置目標にも余裕が減る。今回の中心課題である車輪支持と、重心・支持領域・キャスターの変更を一度に評価する必要が生じるため見送った。高さ125mmそのものが強度不足という結論ではない。

上置き担当の比較配置は、車輪軸をx=90/z=50mmに保ち、上軸を左x=135、右x=45、z≈127.94mmへ置く。軸間90mm、S3Mの30歯同士・270mmベルト・幅10mmを仮置きし、今回の箱内壁を避けてベルト面を|y|=94mmへ寄せる。フレーム高さ75〜105mmを維持する余地があり、上置きを高さだけで却下していない。

FIT0185の連続トルクとベルト用許容ラジアル荷重は確認できていないため、上置き比較ではモーターと継手に加え、別の上軸を二個の軸受で支持する。左右合計でプーリー4、ベルト2、上軸2、追加軸受4、調整台等が増え、下軸も長さを再選定する。0.8〜1.5万円はこの差分の仮枠で、箱形支持や純正接合部への共通変更費は含めない。ベルト比1:1でもモーターの負荷時回転数は要確認で、追加減速は速度余裕を減らす。[DFRobot公式FIT0185仕様](https://wiki.dfrobot.com/fit0185/)。

上置きを採用する条件は、低位置のモーターが電池・配線・必要地上高を妨げるとCADで確認されること、上からの整備性が追加費用と調整作業に見合うこと、ベルト容量・張力・軸受荷重・交換手順を確定できること。現時点ではその必要性が示されていないため、低同軸を選ぶ。

初期機は二駆動輪＋一キャスターを維持する。50mmキャスターの段差能力を認定したためではなく、今回の比較を車輪支持に集中するためである。四点支持へ増やす場合は支持領域だけでなく、床や組立誤差で駆動輪の荷重が減らないよう、揺動・ばね・高さ調整も検討する。[Create 3公式機械資料](https://iroboteducation.github.io/create3_docs/hw/mechanical/)は差動輪の独立懸架と、重心に応じたキャスター追加を示し、[TurtleBot 4公式資料](https://turtlebot.github.io/turtlebot4-user-manual/mechanical/payloads.html)は荷物の低配置と支持範囲を重視している。本機へはこの考え方を採り入れる。

[Waveshare UGV Rover公式資料](https://www.waveshare.com/wiki/UGV_Rover_PI_ROS2)の金属筐体、[タミヤTT-02公式資料](https://tamiya.com/english/products/58743/index.html)のバスタブ形フレームと独立懸架は、面をつないだ骨格や機能別の構成を比較する参考となる。製品と同じ板厚や輪数を選べば、本機にも同じ積載能力が得られるという根拠にはしない。

費用の比較元は、第一案の機械骨格が自加工34,159円、外注枠込み40,159円。電池・電装・機能ガード・アームは含まれない。**ユーザー指定の絶対予算はない。** 第二案の購入額・加工枠・送料・予備費は[費用集計](cost_summary.json)を正とし、この判断文書に別の合計を持たせない。使用数だけでなく購入パックの余りも費用に含める。純正HBLFSN6-SET付属のボルト・ナットは重複計上せず、箱の二面締結等に必要な不足分を追加する。公式仕様を確認したことと、個人購入経路・送料を確定したことは分ける。[ミスミ公式接合部品資料](https://jp.misumi-ec.com/vona2/detail/110300442340/)。

PLAは200×180mmの機器トレイ、型合わせ・穴位置確認治具、配線保持、局所ガードに使う。軸受座、主接合、継続して反力を受けるモーター台は金属とする。機器トレイは載せる機器の実質量、発熱、ボルト座面、長期変形を確認し、電池等の重い部品は別に機械固定する。P1Sの公称造形域は256×256×256mmで、造形物とブリム等がスライサー上の使用可能範囲に収まるよう確認する。[Bambu Lab公式P1S仕様](https://us.store.bambulab.com/products/p1s?country=US&currency=USD&variant=41929890365576)。

将来の組立は、次の順序が成立するようCADと穴図を仕上げる。

1. モーター、KFL08、車輪、ハブ、軸、継手を計測し、穴間隔・軸の差込長・止めねじ位置を確定する。PLA治具は金属部品を加工する前の型合わせに使う。
2. 先入れナットを必要位置へ入れて3030を組む。HBLFSN6のボルト挿入順は公式図の①穴を先とする。直角・平面を確認し、上板と前後ウェブを内外両レールへ仮締めする。
3. 内壁を基準に外壁と軸受を仮組みする。真直な8mm軸を通し、内外壁の平行と軸芯を合わせる。軸を曲げて穴へ押し込んだり、継手で芯ずれを吸収しきった扱いにしたりしない。
4. 車輪・ハブ・カラーを組み、軸方向隙間と止めねじの工具アクセスを確認する。内側上部のM4ナットは対辺をレールに平行に保持し、ねじ頭側を回す。工具厚さと角材の内隅Rを確認する。壁と軸受を段階的に締め、各段階で手回し抵抗と軸方向拘束の変化を確認する。締付けで回転が重くなる場合は芯・平行・拘束を修正する。
5. 車輪軸を基準にモーターを合わせ、継手の差込長と端面隙間を確認する。外壁を取り外して軸受・車輪を交換できること、再組立で芯を再現できることを確認する。
6. トレイ、電池固定、配線、ガードを組む。キャスター全旋回、車輪全回転、電池脱着の包絡を確認し、無負荷回転から負荷試験へ進む。

| 検証段階 | 次へ進むために確認すること | この段階だけでは確定しないこと |

| CAD・部品表 | 公称形状、内外両レールへの固定、軸受支持位置、軸保持、工具と脱着経路、ガードの枠、費用範囲 | 現物公差、締結剛性、許容輪荷重 |
| 受入・加工前 | 購入品の寸法、軸の嵌合、ハブ穴、継手差込長、純正金具の調達、加工見積 | 加工・組立後の自由回転と強度 |
| 組立・台上 | 壁の平行と軸芯、締結後の自由回転、鉛直・横荷重での変位・残留変形・滑り、配線離隔 | 段差衝撃、耐久、連続駆動性能 |

試験荷重と許容変位は、実部品・重心・床条件を確定して設定する。CADの干渉確認、100/200Nの軸配置比較、14kgの駆動力計算は、それぞれ異なる確認である。最新の計算・CAD検査の実施結果は[検証結果](validation_results.json)を参照し、ここに示した今後の試験条件と区別する。未試験項目を合格扱いにしない。
