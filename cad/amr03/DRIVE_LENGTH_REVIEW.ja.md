# 旧FIT構成の駆動部長さ：参考レビュー

2026-09-20。[A2の旧CAD生成コード](build_chassis.py)に残るFIT0185・別軸・KP08構成を確認した。**モーター前面からタイヤ内面は90.3mm、輪中心までは103mmあり、部品点数の多い長い構成である。** ユーザーの明示指示により今後はDDSM115で再設計するため、以下は旧構成の説明と比較に限り、FITの短縮案を現行採用案として進めない。

座標は片側の+y方向。モーター前面y=74mm、タイヤ内面164.3mm、輪中心177mm。右側は対称である。

| 区間 | 長さ | 内訳 |
|---|---:|---|
| 74〜84 | 10mm | ボス6mmと継手までの軸4mm |
| 84〜109 | 25mm | 継手。モーター軸挿入11mm、軸端間2mm、車輪軸挿入12mmを含む |
| 109〜110.5 | 1.5mm | 継手と内側KP08突端の隙間 |
| 110.5〜125.5 | 15mm | 内側KP08、支持中心118mm |
| 125.5〜137.5 | 12mm | 軸受間。4mmの隙間と内側カラー8mm |
| 137.5〜152.5 | 15mm | 外側KP08、支持中心145mm |
| 152.5〜160.5 | 8mm | 外側カラー |
| 160.5〜161.3 | 0.8mm | カラーとハブねじ頭の公称隙間 |
| 161.3〜164.3 | 3mm | 内側に出るハブねじ頭 |
| 合計 | **90.3mm** | タイヤ半幅12.7mmを加えると輪中心まで103mm |

90.3mmの大半は継手・軸受・軸方向保持部品が占める。継手と軸受の間やカラーとねじ頭の間だけを詰めても、大きな短縮にはならない。継手の挿入深さと軸端間隔は現品条件が未確認なので、見た目だけで削らない。

車輪荷重P、軸受間隔L、外側軸受から輪中心までの張出しeとすると、二点単純支持モデルの反力は `R内=−Pe/L`、`R外=P(1+e/L)`、最大曲げは `Pe` となる。比較用100Nでの値は以下。200Nでは反力・曲げモーメントが2倍になる。これらは部品定格や実際の一輪荷重を表さない。

| 支持中心／輪中心mm | L／e | 内側／外側反力 | 最大曲げ |
|---|---|---|---:|
| 現状118・145／177 | 27／32mm | −118.5／218.5N | 3.20N·m |
| 内側だけ125へ移動 | 20／32mm | −160.0／260.0N | 3.20N·m |
| 外側だけ150へ移動 | 32／27mm | −84.4／184.4N | 2.70N·m |

外側支持と車輪を固定したまま軸受間隔を縮めると、反力が増え、張出し曲げは減らない。20mm間隔では現8mmカラーも軸受間に収まらず、そのまま成立する短縮案ではない。

旧FITを維持する場合の比較案としては、外側KP08を145→150mmへ動かし、既存カラー2個を軸受間の125.5〜133.5mmと134.5〜142.5mmへ置ける。軸受の突端間17mmに8+1+8mmが入る。外側KP08の足端156.5mmは支持板端158mmの内側、最外突端157.5mmからハブねじ頭161.3mmまでは3.8mmとなる。ただし、別々の軸受内輪端面へカラーを当てる保持方式になるため、採用品の内輪突出、軸方向遊び、組付けを確認する必要がある。これは車輪支持を改善する参考案であり、モーターからタイヤまでの90.3mm自体は変わらない。

100mm定尺軸を無加工で使った結果、車輪軸y=97〜197mmはハブ外端180.3mmから16.7mm、タイヤ外端189.7mmから7.3mm突出する。たとえば外側10mmを切ってy=97〜187mmとすれば、現CADでは軸先端がタイヤ外面の内側に入り、全幅を394→379.4mmへ縮める余地がある。端部加工・固定部の必要長を確認する条件付きであり、軸受支持位置やモーターとタイヤの距離は変わらない。**定尺無加工は外端の余長を残した理由だが、90.3mmの距離全体を必須にする理由ではない。**

座標の寸法連鎖、反力の力・モーメントつり合い、上記カラーの区間関係をPythonで確認した。DDSM115では継手・別軸・KP08・カラーをこのまま引き継がず、一体車輪の正式取付面から金属支持部と3030への荷重経路を新たに設計する。
