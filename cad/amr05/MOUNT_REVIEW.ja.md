# M0601C_111 専用金属マウントの独立レビュー

2026-09-21。対象は [custom_mount.py](custom_mount.py) の一体切削金具と [build_chassis.py](build_chassis.py) の組付け。**既製ブラケットのモーター受け形状を参照した低背金具を見積候補とする判断を支持する。** 外レール位置、フレーム高さ、長いスペーサーを使わない方針を維持できる。これは公称配置と荷重経路のレビューであり、製作承認・許容荷重・疲労寿命の認定ではない。

**資料で確認した取付条件。** 販売元配布の [メーカー資料 p8](https://d2air1d4eqhwg2.cloudfront.net/media/files/a48110eb-432c-4083-a159-9e0f35913b23.pdf) は、固定側を3本のM2.5、深さ5mm、PCD15.20±0.08、固定端外径19mm（+0.05/−0.15）、三平面までの軸心距離8±0.15mmとする。回転側の深さ4mmとは別であり、旧DDSM115の深さ6mmも引き継がない。資料は購入ロットの実測結果ではない。

[販売元公開STEPへのリンク](https://www.switch-science.com/products/7646) を使った主担当の測定では、固定端面とケース背面の間は15mm。タイヤキットの外形を置いた固定端面から荷重中心までの36.5mmは、キットの軸方向組付け位置が未確定のため**配置仮定**として残す。公開資料からDDTの単輪ラジアル荷重定格は確認できておらず、DDSM115の10kgという値は転記しない。

**既製品との比較。** [DDT-M0601C-BRACKET](https://www.switch-science.com/products/9204) は115×70×25mmのアルミ製で、確認時点6,050円/個。左右2個12,100円に車体側の接続部品が加わる。既製受け部の再構築根拠は [BRACKET_SOURCE_REVIEW.ja.md](BRACKET_SOURCE_REVIEW.ja.md) にある。元品は板厚10mm、**モーター側から凹深3mm、背面肉厚7mm**であり、その逆ではない。

元品の軸位置は幅70mmの中央、高さ方向90mm。軸高50.35mmで姿勢だけ変えた外形高さは次のとおり。幅方向へ逃がすためのレール再配置は含めていない。

| 既製品の姿勢 | 下端〜上端z | 配置上の結果 |
|---|---:|---|
| 通常向き | −39.65〜75.35mm | 床を横切る |
| 90°回転 | 15.35〜85.35mm | 地上高25mmを満たさない |
| 上下反転 | 25.35〜140.35mm | 地上高の公称余裕0.35mm。荷重時のタイヤ変形や摩耗を見込めない |

上下反転から傾けると幅35mmの側端が下がるため、最下端を改善できない。軸から最寄り外周まで25mmある一方、軸からフレーム下面までは18.65mmなので、回転だけでは主板全体をフレーム下面へ収められない。元レール位置で固定面を138mmに合わせると、主板がレールを横切る。

外レールを20mm内寄せし、外面130mmにt5板を足す比較案も、背面肉厚の訂正が必要である。既製金具の平らな背面135mmからモーター座面までは7mmなので、固定面は**142mm**となり138mmではない。そのままなら左右合計で輪距・幅が8mm増える。固定面138mmを守るにはレール位置や接続板をさらに変える必要がある。また、内側レールとの空間を20mmへ狭めると既存の30mm級ガセットの配置も再検討になる。専用案はこれらの変更を避けられる一方、加工費とはめあい確認が新たに必要になる。未見積の専用金具を既製品より安いと断定しない。

**最終専用案の寸法。** 下表は左側。右側も同じ加工品を向きを変えて使う想定で、単位はmm。

| 部位 | 現CADの公称寸法・位置 |
|---|---|
| 外レール3030 | y120〜150、z69〜99。外枠460×300を維持 |
| 車輪 | 軸x90/z50.35、タイヤy153〜196、中心y174.5。輪距349はキット位置の仮定を含む |
| 材料・外形 | A6061-T6を見積指定候補。90×30×34、一体切削 |
| 取付フランジ | x45〜135、y120〜150、z64〜69、厚さ5 |
| 縦ウェブ | x60〜120、y130〜147、z35〜69、厚さ17 |
| 受け凹部 | 入口y147、座面138、深さ9、背面残肉8。ケース背面153まで公称6の間隔 |
| 受け輪郭 | 元の16曲線を外向き0.15オフセット。平面距離8.25、主円弧R9.70。加工公差±0.05は提案値 |
| モーターねじ | 3×M2.5×12、通し穴φ2.8、PCD15.2。頭下座面y130、背肉8、ねじ込み4、資料深さ5に対し公称1の底付き余裕 |

平面距離は最小8.20に対してモーター最大8.15なので、同心配置の平面方向に0.05mmの最小隙間を見込む。主円弧も最小R9.65に対してモーター最大R9.525となる。ただし、これだけで輪郭全体のはめあいは確定しない。隅R、穴位置、入口面取り、表面処理、受け座の直角度、購入品の版を重要寸法として照合する。9mmの受け長さ、外向きオフセット、配線溝、車体への接続は新設計であり、既製品の評価をそのまま継承できない。

**荷重経路。** タイヤの力をローター・内蔵軸受から固定端へ伝え、受けポケットの側面、端面の面圧、M2.5締結で一体金具へ渡す。その後はフランジと3030下面の接触、M6と溝ナットを介してフレームへ流す。ポケットは隙間ばめなので、三平面を設けたことだけを根拠に小ねじを無荷重と扱わない。フランジへ荷重を渡す中間のアングル接合がなくなった点は旧A3からの構造上の改善である。

以下は比較用の輪荷重P=100/200N、トルクT=0.96/2N·mを用いた手計算。100/200Nは実機荷重の保証、試験指定、製品定格ではない。[メーカー資料p15](https://d2air1d4eqhwg2.cloudfront.net/media/files/a48110eb-432c-4083-a159-9e0f35913b23.pdf#page=15) の0.96N·mは18Vでの公表定格、2N·mは拘束トルクであり、許容動作ピークと読み替えない。接線力を `Fx=1000T/50.35` と置くと19.07/39.72Nになる。

接地点(90,174.5,0)の力(Fx,0,P)を、レール下面の接合中心(90,135,69)へ移す。符号付きのモーメントは `Mx=39.5P`、`My=−69Fx`、`Mz=−39.5Fx` [N·mm]。この式には接地高さの腕が入っているので、駆動トルクを別に足さない。

| 比較量 | P100N/T0.96N·m | P200N/T2N·m |
|---|---:|---:|
| 接合中心のMx | 3.95N·m | 7.90N·m |
| 同Myの絶対値 | 1.316N·m | 2.741N·m |
| 同Mzの絶対値 | 0.753N·m | 1.569N·m |
| t5、仮幅90のフランジ曲げ応力 | 10.53MPa | 21.07MPa |
| t5、仮幅60に絞った曲げ感度 | 15.80MPa | 31.60MPa |

曲げ応力は穴のない矩形断面に `σ=6Mx/(bt²)` を用いた比較に過ぎない。幅60を有効幅の保守保証とはしない。実際の荷重分布、穴、ウェブとの接続、工具R、局所曲げ、ねじ座面を省いているため、材質名から降伏安全率を出して「t5で十分」と認定しない。

**M6と3030下面の接合。** 二本のM6はy135の単一列であり、Mxをねじ間の軸力差だけでは受けられない。上向き輪荷重Pにより外側のフランジ面がレールを押し、ねじ引張と接触圧縮が対を作る。圧縮合力がねじ列から外側へaだけ離れる仮定では、`C=39.5P/a`、二本分の追加引張成分は `C−P`。Myの差を全てねじへ割り当てた一本当たりの比較値は `P/2×(39.5/a−1) ± 69Fx/75` となる。

| P/T | 最大追加引張成分：a9.5mm | 同：a15mm |
|---|---:|---:|
| 100N/0.96N·m | 175N | 99N |
| 100N/2N·m | 194N | 118N |
| 200N/0.96N·m | 333N | 181N |
| 200N/2N·m | 352N | 200N |

a9.5は簡略レールの外側接触帯y139〜150の中央、a15は外端150を仮定した感度比較である。接触位置やこの分担は保証していない。表は締付予圧を含む実ボルト軸力ではなく、接触変化・こじり・局所変形も含まない。接合面の摩擦を無視したM6の面内せん断比較は `sqrt((Fx/2)²+(39.5Fx/75)²)` で、13.85/28.85N/本。予圧と摩擦で滑りを抑える評価、滑り後の孔・溝ナットへの荷重、レール溝縁の局所変形は別に確認する。

M6頭径10/孔径6.6の公称座面積は44.3mm²。頭はフランジ端とウェブの双方から2.5mm離れる。座金なしの金属直接座なので、座面の塑性変形と予圧の維持を確認する。公称先端z76、溝ナットz71〜75、溝空間限界77という寸法はねじ込みと底付きの比較であり、ナット引抜き強度の根拠ではない。

**固定端の短い受けとM2.5。** ポケット両端だけで全曲げを受け持つ二点支持の理想化では、座面から荷重中心まで36.5mm、支持間隔9mmとして、P100N時に内端−306N/外端406Nとなる。間隔3mmでは−1,117N/1,217Nになる。深い受けの比較上の利点は見えるが、実際には端面と小ねじも共同で受けるため、これらを接触力や面圧の予測値にしない。

逆にポケットと面摩擦の分担をゼロにして三本へP、Fx、Tを渡すせん断モデルでは、一本の最大値はP100/T0.96で75.0N、P200/T2で153.6Nになる。固定面の曲げ `Mx=36.5P`、`Mz=−36.5Fx` もある。三点を同剛性の軸方向ばねに置き換えた場合、同二条件の引張側最大値は213/430Nとなるが、圧縮側を含むモデルであって実ねじ張力ではない。モーター側の母材、ねじ等級、有効ねじ部、接触分担が未確定なので許容値との合否判定はしない。

**配線・工具・着脱。** 背面スリットを幅7へ戻した最終形状では、下側M2.5穴中心の横偏心6.5818から、穴半径1.4と溝半幅3.5を引いた公称肉厚は1.682mm。頭半径2.25に対しては0.832mmの座面端余裕があり、幅9.5を背面まで貫通させた旧検討の座面欠けを解消している。z41以下の幅9.5への拡幅も、下側頭の最下端z44.3から3.3mm離れる。これらは局所耐力の証明ではない。

主担当の公開STEP断面調査では、保存リードの軸下10〜25mm区間は概ねφ4.8の外形だった。図面の6.5mmは固定端の切欠き寸法であり、線束径の仕様としない。運転時は中央から車体内側へ曲げ、下開き溝は端子を通さず組み付けるために使う。最終の経路予約では曲げR8を確保するため下へ回し、最下端は約28.35mmとなった。金具35mmとは別の地上高として管理する。[配線配置](ELECTRICAL_PACKAGING.ja.md)参照。実ハーネス径、最小曲げR、端子、被覆保護と固定点を現物で決める。

M2.5の工具は車体内側からy正方向へ入れる。上側頭の最上端は60.2mmで、フランジ下面64mmまで3.8mm、フレーム下面69mmまで8.8mmの公称差がある。M6は下面から挿入できるが、床上での工具回転は未検証なので、整備時に車体を支持して輪荷重を抜く。配線の固定点は小ねじの工具経路を塞がない位置へ置く。モーター全体の着脱はねじと配線を解放して外側へ抜く方向で、少なくとも受け長さ9mmを抜ける空間が必要。タイヤ単体の交換は外側から行う想定で、キットの実際のカバー・ねじ・引抜き量を別途照合する。

**CAD確認の範囲。** 本レビューはソースと [validation_results.json](validation_results.json) を読み、上記寸法との一致を確認した。主担当の検査出力は161個の物理部品、全12,880ペアで0.001mm³を超える体積干渉なし。最低固定部32mmは電池クレードルで、金具自体は35mm。機械幅406.6mmと輪距349mmはタイヤキット積み上げの仮定を含む。部品質量と電装枠を合わせた台車推計6.79kgも実測ではなく、タイヤキット250g/輪の仮枠を含む。

本担当は全ペアの形状演算を再実行していない。ねじ山を簡略化し、元STEPの柔軟リード姿勢を除いた検査なので、公差、変形、実配線の曲げを確認した結果ではない。工具軸と仮タイヤの移動は後段の[別検査](mount_service_validation.json)で確認したが、実工具の柄と実タイヤのはめあいは対象外。輪荷重100/200N、部材の曲げ、ボルト群、溝の寸法連鎖はPythonの独立計算で再確認した。

旋回横力Fyを加える場合、レール下面での曲げは `Mx=39.5P+69Fy` [N·mm] となる。有限のタイヤ接地面による旋回ねじり、キャスターの向き変化、段差衝撃、疲労は今回の数値に含まない。三輪差動の比較を四輪スキッドステアと同じ横滑り条件にせず、実床での旋回抵抗・滑り・タイヤ変形を次の確認に残す。
