**材料・加工・締結材を含む比較方法**

既製品は[元データの調査](BRACKET_SOURCE_REVIEW.ja.md)で高さ115mm、軸より下90mm・上25mm。反転配置でも底面は地上25.35mm、上端は140.35mmとなり、旧地上高25mm目標に対する公称差は0.35mmにとどまる。[配置検査](stock_bracket_fit_results.json)では元のレールとの干渉が残った。固定面138とt5取付板を守る案では外レール24mm内寄せと接合金具の再配置が必要になり、その成立・費用は未確定。荷重変形やタイヤのたわみを含む成立保証でもない。既製品価格だけで採用を決めず、配置するための部材・作業も評価する。

基準は[A3のBOM](../amr04/bom.json)と[費用集計](../amr04/cost_summary.json)。自加工47,824円からDDSM115一式25,982円、自作上アングル1,000円、下アングル1,000円、鋼製キー板800円を取り外すと、共通費の暫定残額は**19,042円**になる。新しい製作ブラケットまたは既製ブラケットを排他的に加え、旧自作固定部2,800円を重ねて残さない。

製作ブラケット左右2個の材料・加工費一式を`Q`、既製品用3030取付板2枚の素材・穴加工一式を`P`とする。どちらも未見積であり0円ではない。

| 初回の購入条件 | 低背一体ブラケットを製作依頼する主案 | 既製ブラケット2個＋取付板の比較案 |
| --- | ---: | ---: |
| Taobao約7,000円に適合タイヤ一式を含むと確認できた場合 | **33,042円＋Q＋残る未確定分** | **45,142円＋P＋残る未確定分** |
| Taobao約7,000円にタイヤを含まず、国内キット2個を追加 | **42,282円＋Q＋残る未確定分** | **54,382円＋P＋残る未確定分** |
| 国内表示の本体＋キット、ただし本体欠品 | **57,102円＋Q＋残る未確定分** | **69,202円＋P＋残る未確定分** |

残る未確定分は国内外配送・手数料、発注単位確定後の仮枠差額、残る板部品も外注する場合の加工費など。既製案は取付板・締結の配置数量も未確定。表の数値は最終額や実費範囲ではない。タイヤ付きが未確認の段階では、その付属を理由に9,240円を削らない。逆に付属が確認できれば初回分を二重計上せず、予備・交換キットとは区別する。

旧外注追加枠6,000円は自作アングルの脚切詰め、内R逃げ、鋼製キー異形輪郭などを含む未見積値だった。A4ではこの枠を削除し、**製作ブラケットと残存板部品の作業範囲ごとの見積へ置換**する。上記19,042円は元から旧外注6,000円を含まない。ブラケット見積に材料が含まれる場合は別のアルミ素材代を重ねず、含まれない場合にだけ追加する。キャスター板・ガセットの素材は共通費に残り、その加工が残ることを忘れない。既製案では取付板素材・穴加工も必要。自加工の自己作業費と新規工具代は別。

見積依頼には部品版、STEP、寸法図、左右2個、材質、重要な固定受けの寸法・公差、ねじ穴と面取り、材料・加工・バリ取りの希望範囲をそろえる。納入寸法の検査、送料・税の扱いも確認し、要求精度と価格の両方で比較する。完成ブラケットの材料込み見積と、材料だけの仮枠を直接比較しない。`Q`が12,100円より低いとはまだ判断できず、既製案の取付板・加工・締結・配送まで含めて優劣を決める。

一般締結材2,300円と追加溝ナット28個分1,200円は共通費19,042円に含む仮枠。[最終fasteners.csv](fasteners.csv)で、主案の溝ナット44個＝SET付属16＋追加28、一般締結材の追加66点を照合した。モーター固定はM2.5×12が6本、フレーム固定はM6×12が4本で、A3のM4ねじ・ナット・ワッシャ各12点は撤去。購入パックの単価が不明なため、使用数減少だけで2,300円枠を減らしてはいない。既製比較案の締結数量は別途更新する。

タイヤキットの付属ねじ3本はタイヤ側の費目であり、ブラケット・3030固定ねじを兼ねると推定しない。通信インターフェース・USBケーブルも共通費へ残すが、通信とソフトウェアの適合は別確認。電池・主計算機・電源保護・非常停止・車内配線等の未選定費用を0円とは扱わない。

**交換費用の考え方**

適合が明示されたタイヤキットを購入できる点は、タイヤ単体の供給が未確認だったDDSM115案からの改善になる。ただし販売単位はゴム単体ではなくカバー・ねじ付きキットで、現時点の補修予算は**左右1回9,240円、2回18,480円**。ブラケットや正常なモーター本体を毎回買い直す費用は加えない。将来の在庫・価格・供給期間、実使用での寿命は未保証であり、何年で何回交換するかは実機の摩耗記録から決める。

初期比較には最初に装着するタイヤを必ず含め、維持費比較にはその後の交換分だけを加える。Taobao品は、同一型式・販売仕様と国内補修キットの適合を確認してからこの維持費へ接続する。国内本体欠品や未確認の輸入諸費を隠して、安いモーター単価だけで完成台車が安くなるとは結論しない。

**A4専用費用計算器**

[A3計算器](../amr04/calculate_cost.py)は全行に数値の購入価格があることを前提としていたため、[A4計算器](calculate_cost.py)には未知価格を保持する集計を実装した。`python3 cad/amr05/calculate_cost.py --require-cad --self-test`でBOM.csvとcost_summary.jsonを再生成できる。CSVは基準案の購入15行だけを出力し、比較案を一緒に発注する表にはしない。A3ファイルは履歴として変更していない。

| 項目 | A4での扱い |
| --- | --- |
| 共通BOM | 3030、純正接合部、キャスター、PLA、ストラップ、USB通信等を1回だけ計上。主案のCADと締結数量・見積形状・PLA3点を照合 |
| 調達条件 | モーターはTaobao仮枠／国内欠品参考を別シナリオ。Taobaoタイヤ付属は`unverified`のまま、付属確認時と別購入時を分ける |
| 主案の製作行 | 左右2個の見積を1式とし、`packs=1, pieces_per_pack=2, used=2, pack_price_jpy=null, price_kind=quote_pending`。2個分の見積を受けた後に再び2倍しない |
| 既製比較行 | 国内ブラケット2個12,100円と取付板素材・穴加工を計上。主案の製作行とは同時に加算しない |
| 価格根拠 | 確認済み販売値、旧記録、公式表参考、ユーザー仮枠、未見積を区別。Taobao仮枠へ「税込確認済み」を付けず、輸入諸費の未確認行を残す |
| 加工範囲 | 希望する見積範囲を保存し、受領後は実際に含む材料・加工・税・送料を記録。見積範囲に合わせて重複する素材・配送行を更新する |
| 未知価格 | 未見積は`null`。参考価格小計・仮枠小計・未見積必須行の一覧を出し、必須行が未見積なら総額、A3との総差額、10%予備費込み総額を`null`にする |
| CSV・比較 | 未見積セルは「見積待ち」と表示し0円へ変換しない。各シナリオの有効行だけを合計し、A3から削除／引継ぎ／置換／追加した全行を照合 |
| 保守費 | 初期タイヤと後の交換キットを分離。左右1回9,240円・2回18,480円のキット費を別出力し、初期総額が未定のまま台車全体の累計額を作らない |

未見積の製作行だけを残した場合に総額・予備費込み総額が`null`になることと、タイヤ付属確認時との差が9,240円になることの自動確認は通過した。シナリオの重複行、既製と製作の同時計上、初回タイヤの欠落／二重計上は入力検証で防ぎ、最終CADの締結8種類・溝ナット44個・追加一般締結66点・PLA3点との照合も通過した。10%予備費は見積待ち費用を代用する数字にはしない。
