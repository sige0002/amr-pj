# M0601C_111 専用モータ金具：見積依頼仕様案

作成日：2026-09-21。図番 **AMR-05 / MOUNT-Q01、Rev. A**。

**この資料は見積用。現物照合と最終図面の承認前は製作を保留する。** 2026-09-21にSTEP・PDFをJLCCNCの自動見積へ投入した。[取得結果](MACHINING_QUOTE.ja.md)は2個74.50 USD＋国単位の日本向け送料7.23 USD。正式な図面審査依頼・発注・支払いは未実施で、以下の検査・税等を含む着荷総額の確認は残る。

## 依頼内容

Direct Drive Tech製 M0601C_111 を3030アルミフレームへ固定する、一体のアルミ金具を2個製作する場合の見積を求める。左右で同じ部品を使用する。溶接組立ではなく、一体CNC加工を第一候補とする。

モータの受け部は[既製DDT-M0601C-BRACKETの公開CAD](https://www.switch-science.com/products/9204)にある解析曲線を参照している。**モータ側形状参照、車体側は新規設計**であり、既製品の複製や完全なSTEP変換品ではない。詳しい由来は[BRACKET_SOURCE_REVIEW.ja.md](BRACKET_SOURCE_REVIEW.ja.md)を参照。

## 部品座標と加工箇所

ここではSTEPの外形最小隅を **O=(0,0,0)** とする。元CADが車体座標で保存されている場合は、(45,120,35)を差し引くと下記の部品座標になる。原点出ししたSTEPの場合、この差引きは不要。

Xは幅方向、Yは厚さ方向、Zは高さ方向。モータは+Y側から取り付ける。上の3030接触面はZ=34、フランジ下面はZ=29、モータ軸中心は **X=45、Z=15.35**。軸はY方向。

| 加工・基準 | 部品座標での寸法 |
|---|---|
| フランジ外形 | X=0…90、Y=0…30、Z=29…34 |
| 支持web | X=15…75、Y=10…27、Z=0…34 |
| モータ受け入口 | Y=27 |
| 受け底 | Y=18。入口から深さ9 mm |
| web背面 | Y=10。受け底との間に8 mmの肉厚を残す |
| M6用通し穴 | 2 × φ6.6。軸はZ、中心(X,Y)=(7.5,15)、(82.5,15)、ピッチ75 |
| モータ用通し穴 | 3 × φ2.8。軸はY、PCD15.2、下表の位置 |
| 受け主輪郭 | 元の解析輪郭を外側へ0.15 mmオフセット。主円弧R9.70、回り止め3平面の軸距離8.25 |
| 配線開口・背側 | 幅7 mm、中心X=45。下側へ開放。中央上端はR3.5 |
| 配線開口・モータ側 | 幅9.5 mm、Y=18…27。中央上端はR4.75 |
| 配線開口・下端 | Z=0…6では背側も幅9.5 mm。中央ねじ頭の座面を残すため、全高さを幅9.5にはしない |

モータ用φ2.8穴の中心は以下の3点。穴位置の基準は軸中心X=45、Z=15.35である。

| 穴 | X mm | Z mm |
|---|---:|---:|
| 上 | 45.000000 | 22.950000 |
| 左下 | 38.418207 | 11.550000 |
| 右下 | 51.581793 | 11.550000 |

すべてブラケット側の**通し穴**であり、ブラケットにM2.5やM6のタップを立てる指定ではない。受け部の細かい円弧接続と配線切欠きはSTEPの公称輪郭を参照する。

## 公差案と、製作前に確定する事項

回り止め3平面の軸距離について、見積用の公差案を **8.25 ±0.05 mm** とする。モータ側の同じ距離を8 ±0.15 mmとした場合、ポケット最小8.20とモータ最大8.15との差は片側0.05 mmになる。ただし、この計算が扱うのは**平面部分のみ**である。

主円弧、隅の円弧、深さ、穴位置、実際に納入されるモータの版、バリや表面処理まで含む**全輪郭の公差適合は未確定**。円弧を含む輪郭全体へ、平面寸法の±0.05を自動的に適用しない。穴位置公差、一般公差、接触面の平面度・直角度、必要表面粗さも今回のモデルだけでは確定していない。加工先は見積時に適用予定値と追加費用を提案し、最終図面の承認後に製作する。

特に、次を製作承認前に確認する。

1. 実機の固定ボスと金具の全輪郭が入り、回り止め面が機能すること。必要な逃げ量を現物に合わせて確定する。
2. 工具径・内隅R・底隅Rを加えても、モータ座面が浮かず、軸位置と取付ねじの座面が成立すること。CADの鋭角を加工都合で無断変更しない。
3. 受け底、web背面、3個の通し穴、3030接触面・2個のフレーム穴の位置関係が、合意した公差内にあること。
4. 工場出荷ハーネスとコネクタが開放部へ入り、取付・取外し時にも傷つかないこと。背側7 mmの開口とねじ頭の座面を両立すること。
5. 端部処理を加えた後も、フランジの5 mm厚さとM6ねじ頭座面、モータ用ねじ頭の座面が残ること。

原CADには解析輪郭があるため、その輪郭のはめあいまで画像や寸法図の線幅から推定しない。現状の公称CADでの部品間干渉ゼロは、加工公差、締結強度、耐久性、実組立の保証を意味しない。

## 組立情報（見積金具には締結品を含めない）

- モータ固定：1個当たりM2.5 × 12を3本。背面肉厚8 mmに対する公称ねじ込みは4 mm、モータ側の最大有効深さ5 mm以内。実際のねじ長さ公差・座面・ボス端面位置を現物で再確認する。
- フレーム固定：1個当たりM6 × 12を2本、厚さ5 mmのフランジへ頭を直接着座させる。現設計は座金なし。別途用意する3030用ナットの寸法・ねじ込みも組立時に照合する。
- 見積の金具は左右同形2個。ねじ・フレームナット・モータ・電装品はQに含めない。

## 費用比較の基準

[既製DDT-M0601C-BRACKET](https://www.switch-science.com/products/9204)は、確認時点で1個6,050円（税込）、2個12,100円（税込）だった。**既製品案には別途3030取付板の材料・加工と追加締結品が必要**なので、12,100円だけを既製案の完成費用とはしない。送料条件も揃えて比較する。

専用案の比較対象はQに、その案固有の締結品等を加えた金額。既製品2個＋自作3030取付板一式との完成条件を揃えて選ぶ。専用一体加工が安くなる保証はなく、Qが不利なら、配置・加工方法・既製品を使う案へ戻って比較する。現時点で発注は行わない。

## 図面の再生成

`python3 cad/amr05/make_mount_drawing.py` でSVG/PDFを再生成する。別プロセスのheadless FreeCADでSTEP投影を作り、Rsvg/CairoでPDF化する。原点が車体座標か部品座標かは外形の最小隅から吸収する。主要寸法や体積が変更された場合は、古い注記を残さずスクリプトを停止するので、図面注記も見直す。
